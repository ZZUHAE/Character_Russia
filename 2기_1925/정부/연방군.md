# 연방군

## 1. 개요

군은 연방 전속 사항이다([[국가헌장_조문]] 제5조). 지휘는 셋으로 나뉜다 — **군정(軍政)은 군무부, 군령(軍令)은 참모본부, 의례는 왕관.** 부대 깃발에는 차르의 이름이 있고, 명령서에는 없다.

연방군의 소재지는 국경 요새·군항·해군 기지다. 국내 소요는 구성국 치안 소관이며, 연방군의 국내 투입에는 **이중 열쇠** — 해당 구성국 정부의 요청과 연방 내각의 의결 — 가 필요하다.

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **통수 삼분** | 군정(예산·조달·인사 행정) = 군무부, 두마가 예산으로 통제 / 군령(작전·계획) = 참모본부 / 의례(열병·군기·서훈) = 왕관 — 명목 최고사령관([[국가헌장_조문]] 제21조·[[왕관과_궁정]]) |
| **국내 투입 제한** | 「연방군법」(1920) — 구성국 영내 치안 출동은 **그 구성국 정부의 서면 요청 + 연방 내각 의결**을 요한다. 국경·군항·연방 직할 구역은 예외 |
| **병역** | 구성국별 차등 — 아래 병역표. 복무 연한·소집 사무는 군무부 |
| **방위 임무** | 연방군의 임무는 **연방 영토 전체의 방위 — 구성국의 구분이 없다**(「연방군법」). 어느 구성국에 대한 침공도 연방에 대한 침공이다([[제국의_국체와_연방_구조]] §결속의 원칙) |
| **평시 자체 부대** | 유보 3건 — 한국(치안·의장)·폴란드("평시 편제" 문안)·핀란드([[연방_가입_의정서_일람]]). 전부 평시·영내·치안 한정 |
| **전시 귀속** | **개전과 동시에 유보 부대는 연방군 지휘로 자동 귀속한다** — "평시"라는 한정어의 이면(「연방군법」) |
| **반란의 지위** | 구성국 정부·조직이 연방 시설·연방군을 무력으로 공격하는 경우는 국내 소요가 아니라 **연방 방위 사안** — 이중 열쇠의 적용 밖 |
| **주둔 보장** | 아르메니아 남부 국경 상시 주둔 — 제2호 의정서 부록. 요청에 의한 주둔이므로 투입 제한 조항과 상충하지 않으며, **방위 임무 원칙의 첫 적용례**다 |
| **방첩** | 군무부 소관([[지방행정과_치안]]) |

## 병역표

| 방식 | 적용 | 내용 |
|---|---|---|
| 징병 | 러시아·우크라이나·백러시아·발트 | 일반 병역 의무 |
| 지원병 | 한국·조지아·아르메니아·아제르바이잔·투르케스탄 | 징병 없음 — 지원 입영만 |
| 병역세 | 핀란드 | 징병·지원 모두 없음 — 병역세 납부(제9호 의정서 부록) |

## 3. 구성·조직

| 항목 | 내용 |
|---|---|
| 상비 규모 | 약 **90만** (1925) |
| 배치 무게 | 서부 국경 > 남부 국경 > 극동 (군항 수비) |
| 해군 | 발트·흑해·태평양 — 태평양의 군항은 뤼순·원산·마산포(원산·마산포는 연방 직할, [[한국_왕국]]) |
| 근위 | 의례·수도 의장 임무([[왕관과_궁정]]) |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1918~19 | 동원 해제 |
| 1920 | 「연방군법」 — 통수 삼분·국내 투입 이중 열쇠·병역 차등을 법제화 |
| 1921 | 감군 완료 — 상비 약 90만 |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| 병역 차등에 대한 징병 지역의 이의 — "피의 분담"을 분담금 산식에 반영하라는 요구 | 러시아·우크라이나 의회 ↔ 연방 | **1929 분담금 사정으로 합류** |
| 폴란드 "평시 편제" 문안의 해석 | 폴란드 ↔ 군무부 | 양측 모두 해석을 아껴둠 |
| 총독주 승격 시 치안·수비 사무의 이관 절차 | 극동 ↔ 군무부 | 조문 침묵 |

## 숫자 (기준계)

|---|---|
