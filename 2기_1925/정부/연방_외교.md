# 연방 외교

## 1. 개요

외교·선전강화·영사는 연방 전속이다([[국가헌장_조문]] 제5조). 조약의 당사자는 연방 하나이고, 구성국은 조약 체결권이 없으며, 재외의 연방 시민은 출신 구성국을 불문하고 연방 영사의 관할이다. **밖을 향한 목소리는 하나다.**

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **전속 범위** | 조약 체결·선전·강화·영사 사무 — 유보 예외 없음(열세 구성국 공통) |
| **통상 배석** | 통상·관세 협정 협상에 이해 구성국의 전문위원이 연방 대표단 안에 배석한다 — 서명은 연방 |
| **영사 주재** | 외국 영사관은 구성국 수도에 주재할 수 있다. 인가장(認可狀)은 연방 외무부 명의 |
| **비정치 대표부** | 순례·학술·박람회 대표부는 구성국이 직접 낸다 — 외교 사무로 치지 않는 관행 |
| **재외 국민** | 연방 영사 관할. 여권은 연방 여권 하나 |

## 3. 구성·조직

| 항목 | 내용 |
|---|---|
| 외무부 | 행정 8부의 하나([[연방_내각]]) — 소재 모스크바 |
| 재외 공관 | 단일망 — 대사관·공사관·영사관, 전부 연방 명의 |
| 인력 | 통일 문관시험 경로([[연방_행정과_문관제]]). 동방 근무는 구성국 출신이 실무 축 |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1919.12 | 편입·연방화의 열강 통고 — 구성국 수도 주재 외국 영사관 인가장을 연방 외무부 명의로 갱신 |
| 1920 | 재외 공관 단일화 — 구 보호국·구 대공국 계통의 대외 창구 폐지([[한국_편입_경과_1918_1920]]) |
| 1920~ | 전후 강화 제조약·채무 협정의 당사자 = 연방 — 결과의 큰 줄기는 [[전후_국제_질서]](세부 저해상도) |
| 1923 | 해협 국제 체제 협정 — 상선 자유 통항·비무장. 연방은 영유 없이 통항 보장([[전후_국제_질서]]) |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| **구성국 통상 대표부** — 핀란드(스칸디나비아 통상), 한국 민족계(대일 통상 발언권) | 구성국 ↔ 외무부 | 계류 — 자치령의 단독 조약 소식(1923)이 논거로 유통 |
| "동등 지위 선언"의 외교 조항 | 수반 회의 ↔ 연방 정부 | [[연방_권한_분장]] §5와 한 묶음 |

〔편집 메타 OOC〕 준거 = 영연방 자치령의 표류(1922 아일랜드 자치령화·1923 캐나다 넙치 조약 단독 체결 — 기존 canon의 in-world 신문 소재)와 독일 제국(외교 전속·바이에른 공사관 잔존 관행). 배석·주재·비정치 창구 3장치는 전속 독점의 반대급부로 설계된 숨통 — 독점을 유지하는 값이다. 강화 제조약의 내용(대독·대오·해협)은 외교 패키지에서 별도로 다룬다 — 여기서는 당사자 지위까지만.
