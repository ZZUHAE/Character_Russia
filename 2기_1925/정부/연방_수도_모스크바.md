# 연방 수도 모스크바

## 1. 개요

연방의 수도는 모스크바이나, **모스크바시는 러시아 구성국의 도시**다(시두마·러시아 법제). 연방이 직할하는 것은 그 안의 **수도 구역** — 청사·의사당 일대뿐이다. 크렘린은 수도 구역에 속하지 않는다.

도시는 세 겹이다. **상인의 옛 서울**(대관식의 크렘린·구교도 상인 왕조의 도시), 그 위에 얹힌 **연방 최대의 공업 도시**(방직에서 기계·전기로), 그 위에 얹힌 **연방 행정의 수도**(1920~). 수도 이전은 기능을 갈랐다: 정치·행정·외교는 모스크바로 갔고, **국립은행 본점·거래소는 페테르부르크에 남았다.** 왕관과 궁정도 페테르부르크다. 다만 돈이 다 남은 것은 아니다 — 상업·산업 금융의 중심은 본디부터 모스크바였고, 수도와 공업과 개발이 겹치자 그 무게는 해마다 늘고 있다.

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **수도 지정** | 「러시아에 관한 조직법」과 같은 묶음의 조직법(1919) — 연방 기관 소재지 모스크바 |
| **수도 구역** | 연방 직할([[연방_구성국_일람]]) — 청사·의사당 일대. 구역 밖 시정은 모스크바 시두마(러시아 구성국) |
| **관리** | **수도 관리청**(내무부 소속) — 청사·시설 유지, 경비 조정 |
| **치안** | **모스크바 시경(러시아 구성국 경찰)** — 연방 경찰이 없으므로([[지방행정과_치안]]) 수도 구역의 일반 치안도 시경 소관. 각 기관은 자체 위병(의회 위병·관청 수위)만 둔다 |
| **크렘린** | **황실령**(궁내성 관리 — [[왕관과_궁정]]) — 대관식장(우스펜스키 사원) 포함. 연방 관청 지구는 크렘린 밖 |
| **의사당** | 1920 임시 개원(귀족회관) → **1924 신축 연방 의사당 개원**(두마·상원 동거). 경내 질서만 **의회 경위대**(원내 소속 — 시경이 못 들어오는 유일한 안마당) |
| **외교단** | 외교는 연방 전속 — 각국 대사관 모스크바 이전(1920~24 완료). 공관가 = 아르바트 일대의 구 귀족 저택 |
| **개회 행차** | 차르는 해마다 10월 개회에 기차로 모스크바에 온다([[왕관과_궁정]]) — 크렘린(황실령)에 머물고, 개회사 후 페테르부르크로 돌아간다. 왕관이 수도에 있는 날은 한 해 며칠이다 |

## 3. 구성·조직 (기능 지리)

| 도시 | 있는 것 |
|---|---|
| **모스크바** | 연방 의사당(두마·상원) · 내각 8부 청사 · 연방 대심원 · 연방 문서고 · 외교단 · 수도 관리청 · [[모스크바_연방_대학]]·연방 기술 대학 |
| **페테르부르크** | 궁정(겨울궁전) · 러시아 구성국 정부·의회 · **국립은행 본점 · 증권거래소** · 대형 주식은행 본점들 |
| (분리 사례) | 재무부는 모스크바, 국립은행 본점은 페테르부르크 — 감독 부처와 발권 은행이 밤차 열두 시간 거리 |

**세 겹의 도시**:

| 겹 | 내용 |
|---|---|
| **옛 모스크바** | 크렘린(황실령·대관식장) · 사십사십(40×40) 교회의 종 · **구교도 상인 왕조들**의 저택·자선 병원·화랑 — 표트르 이전의 옛 서울이자 19세기 내내 "장사꾼의 수도". 키타이고로드의 옛 상관 거리가 그대로 관청가가 된 것이 이 도시의 요약 |
| **공업 모스크바** | **연방 최대의 공업 도시**(단일 도시 고용 기준) — 방직("캘리코 모스크바", [[모스크바_중부_공업지구]])에서 전쟁기 군수 전환을 거쳐 **기계·전기·화학으로 확장 중**. 9방향 철도 결절점. 공장 구역 = 자모스크보레치예·동쪽 외곽(레포르토보 방면) — 관청의 종과 공장의 사이렌, 한 도시의 두 시간표 |
| **연방 모스크바** | 수도 구역·의사당·공관가·이주 관료층(1920~) — 위의 두 겹 위에 얹힌 가장 새 층 |

**두 금융의 분업** (그리고 이동):

| 축 | 내용 |
|---|---|
| 페테르부르크 = 국가의 돈 | 발권(국립은행 본점)·국채·증권거래소·대형 주식은행 본점 |
| 모스크바 = 산업의 돈 | 상업은행·상인은행의 본고장(구교도 상인 전통) — 공업 어음·산업 신용의 최대 시장. 1920~ **연방 개발 금융의 실무 수도**: 개발 공채 인수단 사무소·청부 결제·13개 구성국 발주가 도는 곳 |
| 이동 | 수도+공업+개발이 겹치자 돈의 무게중심이 강을 거슬러 오는 중 — 거래소 모스크바 분소 인가 요구(§5) |

**회기의 리듬** (도시의 물때):

| 철 | 도시 |
|---|---|
| 10월 개회 | 아홉 역이 열세 나라의 의원·수행원·청원인을 부려 놓는다 — 하숙·여관 만실, 물가 선행 |
| 겨울 | 회기 절정 — 정치와 사교와 대학 학기가 같은 달력을 산다 |
| 6월 폐회~여름 | 의원 귀향·대학 방학 — 도시가 반쯤 빈다. 하숙료가 내리는 철 |

**다문화의 장**: 의원단·유학생·개발 계약을 좇는 구성국 상인이 상주 인구에 얹힌다. 정교의 도시에 폴란드 가톨릭 성당·타타르 모스크·유대교당·발트 루터교회 — 회기 중 트베르스카야에서 들리는 말이 연방의 언어 표본이다. 동향회 식당·구성국 물산 상점이 관청가 뒷골목의 한 층.

**수도 구역 안의 배치**:

| 구역 | 시설 |
|---|---|
| 키타이고로드 일대 | 내각 8부·총리 관방·법제국·통계국 — 구 상관(商館)·은행 건물을 매입 개조. 상업 지구였던 곳이 관청 지구가 됨 |
| 강변 의사당 구역 | 신축 연방 의사당(1924) — 두마 회의장·상원 회의장·합동 회랑 |
| 구 재판소 청사 | 연방 대심원(1920 개원) |
| 아르바트 일대 (구역 밖) | 공관가 — 대사관들이 구 귀족 저택을 사들임. 수도 구역이 아니라 모스크바시 관할 |

**수도의 사회** (이전이 만든 것):

| 사실 | 내용 |
|---|---|
| 관료 이주 | 페테르부르크에서 관청을 따라 온 문관·고원과 가족 — 수만 가구. 도시 인구가 한 세대 몫만큼 앞당겨 늘었다 |
| 주택난 | 셋집·하숙의 전성기 — 구 귀족·상인 저택의 방 쪼개기, 관청 인근 하숙료가 도시 물가의 선행 지표가 됨 |
| 말씨 | 거리에 페테르부르크 말씨 — 토박이 상인 도시와 이주 관청 사회가 한 도시에 두 겹으로 얹힘 |
| 지면 | 각 신문 모스크바 지국 상설 — 정치면은 모스크바발, 금융면은 페테르부르크발로 갈라짐 |
| 회선 | 전신·전화 간선 증설 — 두 수도 간 회선이 연방에서 가장 붐비는 선 |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| 수도 구역 경계 세부 (편입 가구·도로의 범위) | 수도 관리청 ↔ 모스크바 시두마 | 미확정 — 바쿠 직할 경계와 같은 유형 |
| 국립은행 본점 이전론 | 재무부 ↔ 국립은행·페테르부르크 금융계 | 논의만 반복 |
| **거래소 모스크바 분소 인가** — 산업·개발 금융이 커지며 상공계가 요구 | 모스크바 상공계 ↔ 페테르부르크 거래소·상공계 | 계류 — 페테르부르크 이전 보상 요구([[러시아_구성국]])와 정면 연동 |

---

〔편집 메타 OOC〕 전면 직할(워싱턴 DC형)은 미채택 — canon "모스크바 일부"의 유지이며, 도시를 구성국에 두고 구역만 떼는 쪽이 "얇은 연방"과 정합. 시경이 연방 의사당 앞 치안을 맡는 것은 연방 경찰 0 원칙(P6)의 수도판. 크렘린=황실령은 대관 의례(13칭호)의 무대라는 지위의 귀결. **금융 재설계(2026-08-11, 사용자 방향 "거대도시에 금융 부재는 부자연 + 공업 강화")**: 실제사 준거 — 모스크바는 본디 상인·구교도 자본의 상업은행 본고장이고 페테르부르크는 주식은행·거래소의 도시(두 금융의 실재 분업). 구 canon "돈은 페테르부르크"는 발권·거래소로 한정 유지하고, 모스크바에 산업·개발 금융을 명시 + 무게중심 이동을 현안화. 공업 최대 준거 — 중부 공업지구는 실제로 노동자 수 러시아 최대 집적. 세 겹 구조·회기 리듬·다문화 절 = 소설 「원과 루블」 2부 무대 수요로 상세화.
