# 연방 규모 일람 (1925)

> 각 제도 노트에 흩어진 숫자의 종합 기준계 — **전부 크기 감각용이며 못박는 사실이 아니다.** 어긋나면 개별 노트가 우선. 1기의 짝 = [[거시_회계_시트]](1915).

## 국토·인구

| 항목 | 값 | 비고 |
|---|---|---|
| 국토 | **~2,300만 km²** | 세계 육지의 약 6분의 1 — 발트에서 태평양·한반도까지 |
| 인구 | **~2억 3,000만** | 구성국 13 — 배분은 [[연방_구성국_일람]] |
| 최대 도시 | 모스크바 ~220만 · 페테르부르크 ~180만 | 두 수도([[연방_수도_모스크바]]) |
| 시민권 | 연방 시민권 단일 — 구성국 간 이동·거주 자유 | 예외: 핀란드 자체 명부([[핀란드_대공국]]) |

## 경제

| 항목 | 값 | 비고 |
|---|---|---|
| 국민소득(NNP) | **~250억 루블** (연방 루블) | 전전 수준 회복 + 편입분. 1인당 ~110루블 |
| 수출 | ~15억 | 곡물·목재·유류 — 흑해 출구는 해협 통항 보장([[전후_국제_질서]]) |
| 수입 | ~12억 | 기계·설비 중심 |
| 철도 | **~8만 km** | 극동~한반도 종관 연결선 건설 중(1927 목표 — [[동방_개발_계획]]) |
| 화폐 | **연방 루블**(1924) + 유보 화폐 2(마르카·원) | [[연방_재정과_화폐]] |

## 연방 재정

| 항목 | 값 | 비고 |
|---|---|---|
| 연방 세출 | **~15억 루블** | NNP의 ~6% — 얇은 연방의 재정 크기 |
| 세입 구성 | 관세 ~35% · 소비세 ~35% · 철도우편 ~20% · 분담금 ~10% | [[연방_권한_분장]] |
| 세출 대강 | 군무 ~25% · 채무 상환 ~15% · 철도·체신 운영 ~30% · 행정·기타 ~30% | 개발 투자는 세출 밖 — 개발 공채([[연방_재정과_화폐]]) |
| 외채 잔액 | **~60억 루블** | 상환 연장 협정 체제 |
| 구성국 재정 합계 | ~12억 | 직접세 — 열세 곳 합산. 공공 재정 총계 ~27억 = NNP의 ~11% |

## 사람과 무력

| 항목 | 값 | 비고 |
|---|---|---|
| 연방 문관 | ~12만 | 통일 문관시험 경로([[연방_행정과_문관제]]) |
| 고원(雇員) | ~25만 | 시험 없는 현지 채용 하급직 |
| 상비군 | **~90만** | 전전 ~140만에서 감군([[연방군]]) |
| 해군 | 3함대 (발트·흑해·태평양) | 군항 직할([[연방_구성국_일람]]) |

## 대표

| 항목 | 값 |
|---|---|
| 두마 | 524석 (직선 — [[두마_선거법_1919]]) |
| 상원 | 124석 (구성국 배분 — [[국가평의회]]) |
| 유권자 | ~5,600만 + 핀란드 명부 (1919 기준 — 1929 재획정 대기) |

---

〔편집 메타 OOC〕 산출 근거: NNP는 1기 기준계(1915년 230억 R)의 전후 회복 + 한국·갈리치아·포즌 편입분을 연방 루블로 환산한 크기 감각. 연방 세출 15억(NNP 6%)은 직접세 없는 간접세 연방의 상한 — 독일 제국·1913 이전 미국 연방의 재정 비중대와 같은 급. 검산 셋: 채무 상환 15%×15억 = 2.25억/외채 60억 ≈ 연 3.75%(연장 협정 금리대와 정합) / 군무 25% ≈ 3.75억/90만 명 ≈ 병사당 400루블대(평시 유지비 감각) / 공공 재정 총계 11%는 1920년대 유럽 하위권(복지 국가 이전 + 교육·토지·노동이 구성국 몫이라 연방 통계에 안 잡히는 구조). 숫자는 전부 기준계 — 회차·노트가 이보다 정밀한 수를 요구하면 그때 개별 확정.
