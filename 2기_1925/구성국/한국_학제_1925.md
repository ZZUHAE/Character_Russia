# 한국의 학제 (1925)

## 1. 개요

한국의 학교 제도는 **학부(學部) 소관**이다 — 교육은 유보 사항이라 연방 법령이 미치지 않는다([[연방_권한_분장]]). 근거 법령은 **「학제령」(1921)** 으로, 광무 연간의 소학교령(1895)·중학교 관제(1899)를 계승·정비한 것. 사다리는 서당(학제 밖)—소학교—중학교—전문학교로 오르고, 수업어는 전 단계에서 조선어다.

## 2. 조문·규정 (「학제령」 1921 골자)

| 단 | 규정 |
|---|---|
| **소학교** | 6년제(군 이하 지역은 4년 단축 과정 병존). 관립·공립. 수업료 소액. 개량 서당(교과 신고를 마친 서당)은 단축 과정으로 인정 |
| **중학교** | 5년제. 입학 = 소학교 졸업 또는 검정 시험. 관립(도별 1교) + 사립(인가제) |
| **전문학교** | 3~4년제 — 법률·의학·상업·사범·공업. 입학 = 중학교 졸업 |
| **사립학교** | 학부 인가제 — 요건은 설립 재산·교사(校舍)·교원 자격의 셋. 교과는 학부에 신고로 족하다. 국고 보조 없음 — 수업료와 찬조금으로 운영 |
| **수업어** | 조선어. 러시아어는 중학교 이상의 외국어 과목(선택) — [[한국_사회_1925]] |
| **여학교** | 소·중 각 단에 병설 또는 단설 가능. 규정은 남학교와 같다 |
| **관비 연방 유학생** | 학부 주관 연 선발·파견 — 연 30명 내외, 학교 추천 + 한성 본시험(러시아어·산술·작문). 여비·학비 관비, 생활비 자담. 파견 전공에 개발 인력 수요 반영([[동방_개발_계획]]). **여학생 몫은 1923년부터 약간 명**(모스크바·페테르부르크 여자 과정 한정). 운영 실제는 오래 한성 학교들의 추천 명단 중심 — **1925년 모스크바 국립대학의 구성국 학생 모집이 공개 경쟁 시험으로 열리며 지방 인가 학교·여학생에게 응시 길이 확대**(§4) |
| **취학 의무** | 규정 없음 — 의무교육은 국회 계류(§5) |

## 3. 구성·조직

**감독 계통**: 학부(대신—학무국·편수국) → 도 학무과. 교과서는 편수국 검정.

**학교의 분포** (기준계):

| 종별 | 규모 |
|---|---|
| 서당 | ~1.8만 개소 — 취학 입문의 최다 경로. 개량 인가는 그중 일부 |
| 소학교 | ~1,400교 · 재적 ~40만(학령의 2할) |
| 중학교 (관립) | 13교 — 도청 소재지 |
| 중학교 (사립) | ~30교 · 관립 포함 중학 재적 ~2.5만 |
| 전문학교 | 6교(한성 4·평양 1·원산 1) · 재적 ~3천 |
| 여학교 | ~30교(소·중 합산) — 한성·평양·개항장 |

**사립학교의 설립 주체 세 갈래**: ①상인·객주 조합(개항장·철도 도시 — 원산·부산·인천·함흥) ②문중·계(내륙 군읍) ③교회(장로·감리·정교 — 평양·한성·원산). 관립 중학이 도별 하나뿐이라 **지방 도시의 중등 수요는 사립이 받는다** — 신설 인가의 대부분이 개항장과 철도 연선에 몰려 있다.

**학제 밖의 학교**:

| 기관 | 소속 |
|---|---|
| **철도학당** | 연방 철도 계통 — 별도 선발 시험, 한국 학제와 무관([[한국_사회_1925]]·[[동방_개발_계획]]) |
| 연선 철도 학교 | 연방계 — 한국 학제 밖의 학교가 한국 땅 위에([[한국의_연방_풍경_1925]], 계류 현안) |
| 노어 강습소·야학 | 민간 — 인가 대상 아님. 개항장·철도역 도시에 성업 |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1895 | 소학교령·한성사범학교 관제 |
| 1899 | 중학교 관제 |
| 1900년대 | 사립학교 설립기 — 상인·교회·문중의 학교가 개항장·서북에서 늘다 |
| 1915 | 철도학당 개설(협약 제11조, 견습 연 20명) |
| 1920 | 교육 유보 발효 — 학제는 한국 소관으로 |
| 1921 | 「학제령」 공포 — 소학교·중학교·전문학교·사립학교 인가의 현행 체계. 관비 연방 유학생 파견 개시 |
| 1922~ | 소학교 확장기 — 개발 세입과 무부채 재정의 배당([[한국_왕국]]) |
| 1923 | 관비 유학생에 여학생 몫 신설 — 여자 과정 한정 |
| 1924 | 철도학당 확대 개편(동방 개발 인력 수요) |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| 의무교육 도입 — 재원이 걸림 | 국회 문교 논쟁 | 계류([[한국_사회_1925]]) |
| 러시아어 교과 확대 | 협력계 실용론 ↔ 민족계 | 연례 논쟁([[한국_사회_1925]]) |
| 연선 철도 학교 관할 | 한국 학부 ↔ 연방 철도 계통 | 계류([[한국의_연방_풍경_1925]]) |
| 사립학교 국고 보조 신설안 — 인가 요건 강화와 한 묶음 | 학부 ↔ 사립학교 측 | 국회 계류 |
| 서당 처리 — 개량 인가 확대 vs 방임 | 학부 학무국 | 방침 미정 |

〔편집 메타 OOC〕 명칭의 원천 = 광무 학제 실제사(소학교령 1895·중학교 관제 1899 — POD 이전 공유 역사). 어휘 가드레일: 보통학교·고등보통학교 등 일본 교육령(1906·1911) 계열 명칭은 이 세계에 존재하지 않으므로 미채용 — 기존 [[한국_사회_1925]]의 해당 표기도 이 노트에 맞춰 정합(소학교·중학교로). 사립학교 층의 준거 = 실제사 1900년대 사립학교 설립 붐(오산 1907·대성 1908 등)이 사립학교령(1908)류의 탄압 입법 없이 20년 성장한 형태 — "관립이 못 따라가는 속도를 민간 자본이 메운다"가 이 학제의 구조. 학교·학생 수는 실제사 1925년 조선 규모를 기준계로 옮긴 것(못박는 사실 아님). 원산 전문학교 1교는 상업전문 — 개항장 상인 자본의 정점. 연방 첫 세대(1908~10년생) 서사의 무대 문서: 지방 도시 사립 중학교가 그 세대의 교실이다.
