# 국가평의회 (상원)

## 1. 개요

연방의 상원. **124석**을 구성국별로 배정하고, **각 구성국 의회가 선출**한다. 의원은 훈령에 구속되지 않고 **개인 표결**한다. 입법권은 없다 — 두마가 만든 법에 대해 **한 번 다시 생각하라고 요구할 권한**과, 구성국 사이의 다툼을 조정할 권한, 그리고 **헌장 개정에 대한 동의권**을 가진다.

## 2. 조문·규정 (골자) — 「국가평의회법」(1921)

| 항목 | 내용 |
|---|---|
| **정수** | 124석 — 구성국별 배정(§3). 두 반(班) 각 62석 |
| **선출** | 각 구성국 의회가 자국 몫을 선출. 총독주는 의회가 서기 전까지 참사회가 대행(헌장 부칙 제8항 준용) |
| **임기** | 8년. **4년마다 절반(한 반씩) 개선(改選)** — 새로 선 구성국 의회가 자국 몫의 개선분을 뽑는다 |
| **자격** | 35세 이상 제국 시민. 두마 의원·각료 겸직 금지 |
| **표결** | 개인 표결. 훈령·일괄 행사 금지 |
| **재의 요구** | 두마 통과 법률안 이송 후 **30일 내 재적 과반으로 1회** 재의 요구 가능 → 두마가 **재적 과반으로 재의결**하면 법률로 확정 |
| **분쟁 조정** | 구성국 간 경계·관할 분쟁의 조정(調停) — 재정(裁定)이 아니며 강제력 없음 |
| **분담금** | 분담금 사정(査定)의 심의([[연방_권한_분장]]) |
| **헌장 개정** | 개정안에 대한 **재적 3분의 2 이상의 동의**([[국가헌장_조문]] 제23조) — 부결선 = 3분의 1 초과 = 42석 |
| **조직** | 의장은 의원 중 호선(임기 1년). 소재 모스크바, 회기는 두마 회기와 병행 |

## 3. 구성 (구성국별 배정)

배정은 1919년 가입 협상의 합의(반당 62석)를 두 반으로 시행한 것.

| 구성국 | 의석 | 반당 |
|---|---|---|
| 러시아 | **36** | 18 |
| 우크라이나 | 16 | 8 |
| 폴란드 | 10 | 5 |
| 투르케스탄 | 10 | 5 |
| 한국 | 8 | 4 |
| 시베리아 | 8 | 4 |
| 백러시아 | 6 | 3 |
| 발트 | 6 | 3 |
| 극동 | 6 | 3 |
| 핀란드 | 6 | 3 |
| 조지아 | 4 | 2 |
| 아제르바이잔 | 4 | 2 |
| 아르메니아 | 4 | 2 |
| **계** | **124** | **62** |

- 헌장 개정 동의 부결선(3분의 1 초과) = **42석.** 러시아 단독 36.
- 상원은 언제나 **전임 의회들이 뽑은 반과 현임 의회들이 뽑은 반**으로 이루어진다.

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1919 | 헌장 부칙 제6항 — 국가평의회의 지위·권한을 별도 법률에 위임. 가입 협상에서 구성국별 배분(62) 합의 |
| 1921 | 「국가평의회법」 제정 — 124석 두 반, 구성국 의회 선출, 개인 표결. **첫 선출**: 전원을 뽑고 추첨으로 4년반·8년반 배정. 총독주 몫은 참사회가 선출 |
| 1923 | 분담금 사정 파동 조정 — 유예 3국과 연방의 타결 중재 · 선거구 조기 재획정 법안에 **첫 재의 요구** 행사(두마 재의결 정족 미달로 폐기) |
| 1925 | **첫 정기 개선** — 1924년에 선 구성국 의회들이 한 반(62석)을 새로 선출. 총독주 몫도 처음으로 선출 의회가 뽑음 |

〔편집 메타 OOC〕 준거: 선출 방식 = 미국 상원 1913년(수정헌법 17조) 이전의 주 의회 선출 — 1925년 시점의 시대 표준. 부분 개선 = 프랑스 3공화국 상원(300석·9년·3년마다 1/3, [Senate of the Third Republic](https://en.wikipedia.org/wiki/Senate_(French_Third_Republic)))을 본작의 4년 선거 주기에 맞춘 것. 첫 선출 후 추첨 배반 = 미국 상원 1789년 방식. 정부 임명·훈령 일괄(독일 연방참의원형)은 채택하지 않음 — 개인 표결과 의회 선출이 세트. 규모 검산: 미국 96석/1.15억·프랑스 300석/4천만 대비 124석/2.12억. 1919 협상 배분 62는 "반당 62석"으로 계승되어 canon 보존.
