# 정당 체계

## 1. 개요

두마의 정당 지형은 **일당 우위**다 — 전환을 이끈 연합(행정 관료·[[제국_산업동원_협의회|협의회]] 상공 자본·구 두마 자유주의)이 **진보당**으로 굳어 여당이고, 야당은 파편이다. 정당은 선거보다 늦게 태어났다: 1920년 첫 총선은 무소속·명망가 선거였고, 원내 클럽들이 결집해 당이 된 뒤 **1924년 총선이 첫 정당 선거**가 됐다.

## 2. 원내 구성 (1925, 두마 524석)

| 세력 | 의석 | 기반 |
|---|---|---|
| **진보당** (여당) | ~255 | 도시·공업 선거구, 관료·상공·전문직. 내부에 관료 결과 산업 결(협의회 계보)의 두 흐름 |
| 한국 협력계 | ~22 | 진보당과 원내 제휴 — **과반(263)은 이 제휴 위에 선다** |
| **농민동맹** (야당 최대) | ~90 | 농촌 선거구, 젬스트보 명망가. 토지개혁·재획정 반대가 축 |
| **국민동맹** | ~45 | 보수·질서파, 구 궁정 인맥·교회 명사. 왕조 조항은 지지, 내각을 공격 |
| 폴란드 콜로 | ~30 | 구성국 몰표 회파 |
| 무슬림 회파 | ~25 | 투르케스탄·캅카스 |
| 한국 민족계 회파 | ~20 | 독자 회파([[한국_왕국]]) |
| 핀란드 의원단 | ~11 | 자체 자격 선거([[두마_선거법_1919]] 특례) |
| 노동파 | ~14 | 등록 사업장 노동자 선거구 — 합법 의회 소수파 |
| 기타 회파·무소속 | ~12 | 1920년 명망가 정치의 잔재 |
| **계** | **524** | |

## 3. 연혁

| 연도 | 사실 |
|---|---|
| 1919 | 선거법 제정 시 비례대표 부결 — "명부를 낼 정당이 없다" |
| 1920 | 제1차 총선 — 무소속·명망가 다수. 개원 후 원내 클럽 결집 시작 |
| 1921~22 | 농민동맹(젬스트보 기반)·국민동맹 조직. **진보당 창당** — 관료·산업·자유주의 세 클럽 통합 |
| 1924 | 제2차 총선 — 첫 정당 선거. 진보당 여당 확립, 농민동맹 야당 최대. 같은 해 러시아 의회 선거에서 농민동맹·국민동맹 연합이 러시아 정부 장악([[러시아_구성국]]) |

〔편집 메타 OOC〕 준거 = 일당 우위제(일본 정우회·인도 국민회의형): 전환의 월계관을 쥔 정당이 장기 여당, 야당은 파편. "제도가 정당보다 먼저"(소선거구가 굳은 뒤 정당이 그 틀에 맞춰 형성)는 선거법 canon의 귀결. 원역사 정당명(카데트·10월당)은 분기상 직수입 불가라 일반명사형 명명(진보당은 실존 계열명이되 사건 의존성 없음). 의석 수는 기준계 — 진보당 단독 과반 미달 + 한국 협력계 22석이 과반의 문지방이라는 구조만 유지하면 조정 가능. 정당 내부 조직·인물은 의도적으로 얕게 둠(사용자 지시: 현 단계 과잉 상세화 금지).
