# 구성국 정부 구성

## 1. 개요

열세 구성국의 정부가 서는 방식은 **한 문법의 열세 판본**이다. 자치 구성국 10곳의 기본법은 헌장 제12조를 그대로 받아 적었다 — **수반은 그 나라 의회의 신임으로 정한다.** 총독주 3곳만 연방이 행정 수반을 임명한다. 선거는 전 연방이 **4년 주기 같은 해**에 치른다(1920·1924·1928 — "선거의 해").

## 2. 조문·규정 (공통 문법)

| 항목 | 내용 |
|---|---|
| **수반 선출** | 구성국 의회가 **재적 과반**으로 수반 신임 의결 → 왕이 그 구성국의 칭호로 임명. 임명장 부서 = 전임 수반 |
| **각료** | 수반 제청으로 임명. 정부는 자국 의회에 책임 |
| **불신임** | 재적 과반. 후임 신임까지 직무 수행 |
| **의회 임기** | 4년 고정 — 해산 제도 없음(연방과 동일 문법) |
| **재가** | 구성국 법률도 기일부 재가(헌장 제9조 미러) — 왕의 침묵은 재가다 |
| **상원 몫 선출** | 자국 의회가 [[국가평의회]] 배정 의석을 선출 — 4년마다 개선분 |
| **연방 접점** | 수반은 수반 회의 좌석([[연방_권한_분장]])을 가진다 |
| **총독주 특례** | 총독 = **연방 총리 제청 + 왕 임명**(부서 = 연방 총리). 임기 규정 없음. 의회(1924~)는 입법·예산 의결, 행정은 총독 |

## 3. 구성 (구성국별 수반)

| 구성국 | 수반 명칭 | 형태 |
|---|---|---|
| 러시아 | 수상 | 의회 신임([[러시아_구성국]]) |
| 우크라이나 | 장관회의 의장 | 의회 신임 |
| 한국 | **총리대신** | 국회 신임([[한국_왕국]]) |
| 폴란드 | 수상 | 의회 신임 |
| 백러시아 | 장관회의 의장 | 의회 신임 |
| 발트 | 장관회의 의장 | 의회 신임 |
| 핀란드 | **원로원 의장** | 합의제 원로원 — 의회 신임 (대공국 전통 유지) |
| 조지아 · 아르메니아 · 아제르바이잔 | 수상 | 의회 신임 |
| 시베리아 · 극동 · 투르케스탄 | **총독** | 연방 총리 제청·왕 임명 |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1919 | 각 구성국 기본법(조직법·의정서 부속)에 공통 문법 규정 |
| 1920 | 첫 구성국 의회 선거 — 첫 의결로 의정서 추인, 이어 첫 수반 신임. 총독주 3곳은 임명 참사회 |
| 1924 | 제2차 선거("선거의 해") — 총독주에도 선출 의회 개원, 행정 수반은 총독 유지 |

〔편집 메타 OOC〕 공통 문법 = 헌장 제12조의 구성국판 복제(연방 설계의 대칭 원리). 임명장 부서 = 전임 수반은 부서 원칙의 순환 해법. 핀란드 원로원은 대공국기 실제 통치 기구 명칭의 존속. 총독주 절차는 잔여권 대행 법리([[연방_권한_분장]])의 인사 측면. "선거의 해" 동기화는 해산 제도 부재의 귀결 — 임기가 어긋날 계기가 제도에 없다.
