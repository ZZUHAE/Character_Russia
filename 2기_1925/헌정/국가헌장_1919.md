# 국가헌장 (1919)

## 1. 개요

러시아 제국 최초의 성문 헌법 문서. **전문(前文)과 26개조, 부칙 9항**이 전부다. 통치의 세부가 아니라 **권력의 소재**만 정한다 — 입법과 신임은 두마에, 통치는 내각에, 왕관과 의례는 황제에게. 제1장이 제국을 **13개 구성국의 연방**으로 규정한다([[제국의_국체와_연방_구조]]).

1919년 12월 6일 공포, 1920년 1월 1일 시행. 1925년 현재 시행 6년차, **개정 0회.** 조문 전문은 [[국가헌장_조문]].

## 2. 조문·규정 (골자)

| 장 | 조 | 내용 |
|---|---|---|
| 제1장 국체 | 1~5 | **국호 = 유라시아 연방**·세습군주국(제1조)이며 **구성국의 연방**(제2조). 황제는 각 구성국에서 정해진 칭호로 군주를 겸한다 — 13칭호 열거(제3조). **모든 국사 행위는 부서(副署)를 요한다**(제4조). 연방·구성국 권한 배분은 조약과 법률로(제5조) |
| 제2장 입법 | 6~11 | 입법권은 두마에(제6조). 법률 = 두마 의결 + 재가(제8조). **재가 기일 30일 — 기일 내 재가가 없으면 효력 발생**(제9조). 정기 회기의 소집·개회 기일은 누구도 미룰 수 없다(제10조). 두마 조직·선거는 별도 법률(제11조 → [[두마_선거법_1919]]) |
| 제3장 정부 | 12~17 | **"총리는 두마의 신임으로 정한다"**(제12조). 각료는 총리 제청(제13조). 내각은 두마에 책임(제14조). 예산 법률주의(제15조) |
| 제4장 황제 | 18~22 | 서훈·영전(제18조), 사면(제19조), **명목 최고사령관 — 지휘·운용은 법률이 정하는 기관에**(제20조), 개회·의례 주재(제21조). **대권은 열거된 것에 한한다**(제22조) |
| 제5장 개정 | 23~26 | 개정 = 두마 재적 3분의 2 + **구성국 원의 3분의 2 동의**(제23조) + 재가 기일 60일(제24조). **제1조(왕조)와 제2조(연방)는 개정 불가**(제25조) |
| 부칙 | 9항 | 공포·시행일(제1항) · 1920년 첫 선거(제2항) · 현 내각 존속(제3항) · 전시 조달 조사 존속·완결 의무(제4항) · **황실비 연 1,800만 루블 10년 정액**(제5항) · 국가평의회는 별도 법률(제6항) · 유보권 조약 동시 발효·십 년 갱신(제7항) · 총독주 임명 참사회(제8항) · 구법령 존속(제9항) |

## 3. 하위 법령 구조

헌장은 골격만 정하고 세부를 법령에 미룬다.

| 법령 | 제정 | 내용 |
|---|---|---|
| 두마 선거법 | 1919 | [[두마_선거법_1919]] |
| 러시아에 관한 조직법 | 1919 | 러시아 구성국의 의회·정부([[러시아_구성국]]) |
| 내각법 | 1920 | 내각 조직·불신임 절차([[연방_내각]]) |
| 두마 조직법 | 1920 | 회기·의사 절차·신임 절차([[두마_조직과_운영]]) |
| 국가평의회법 | 1921 | 상원 124석 — 구성국 의회 선출·개인 표결([[국가평의회]]) |
| 유보권 조약 9통 | 1919 | [[연방_가입_의정서_일람]] — 십 년 갱신 |

## 숫자

| 항목 | 값 | 비고 |
|---|---|---|
| 조문 | 전문 + 26개조 + 부칙 9항 | 동시대 최단급 헌법 문서 |
| 재가 기일 | 법률 30일 / 개정 60일 | 1923년 1회 만료 |
| 개정 문턱 | 재적 2/3 + 기일부 재가 | 개정 불가 조항 2개(제1·2조) |
| 황실비 | 연 1,800만 루블 (10년 정액) | 전후 인플레로 실질 가치는 해마다 감소 |

---

〔편집 메타 OOC〕 헌장이 짧은 것은 "합의 못 한 것을 안 적는" 협상의 산물이라는 설정 — 침묵들이 후속 패키지의 팔 자리다. 제9조 기일부 재가는 전시 대위임 칙령 제2조의 유산(소설 접점). 제22조 열거주의의 값이 부칙 제5항(황실비)과 제25조(왕조 조항 잠금)라는 거래 구조. 수치는 기준계([[거시_회계_시트]] 정신).
