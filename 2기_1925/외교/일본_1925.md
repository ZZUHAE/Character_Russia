# 일본 (1925)

> 1915년 단면과 패전·중립의 경위는 [[일본_제국]]·[[일본_육군_해군_파벌]](1기). 여기엔 1925년의 좌표만.

## 1. 개요 — 도약 없는 이십 년

1925년의 일본은 **두 번의 기회를 놓친 나라**다. 1905년의 패전이 대륙의 발판(극동 이권·남만주)을 걷어 갔고, 대전 불참이 전쟁 경기를 비껴가게 했다 — 교전국에 판 것은 잡화와 원자재 수준이었다. 조선도 만주도 시장이 아니고, 인구는 늘고, 수출할 곳은 좁다.

그 갈증 위에 **두 일본**이 있다: 통상으로 살 길을 찾는 정당 내각과, 잃은 것을 되찾자는 군부의 수복론.

## 2. 정치 — 두 노선

| 노선 | 내용 |
|---|---|
| **정당 내각 (집권)** | 패전이 군부의 위신을 꺾은 자리에서 자란 의회 정치 — 긴축·통상·협조 외교. **대연방 통상 확대가 제1과제**: 연방 관세동맹의 문(부산)을 넓히는 것 |
| **군부 수복파 (음지)** | 동아시아 수복 의지의 계승자들([[일본_육군_해군_파벌]]) — 육해군은 여전히 분열이라 단일 국책이 못 됨. 1917년 공작 노출의 기억으로 **휴면 중이되 해산된 적 없음** |
| 사회 | 인구압·쌀 소동의 기억·도시 노동 문제 — 갈증의 정치가 어느 노선의 연료가 될지는 열려 있다 |

## 3. 대연방 관계

| 항목 | 내용 |
|---|---|
| 국교 | 정상 — 하얼빈 조약 체제(1905). 배상은 1915년 완납으로 종결([[일본_제국]]) |
| **통상** | 제한적 — 대일 교역은 부산 창구로 좁혀져 있다([[한국의_연방_풍경_1925]]). 일본의 확대 요구가 **부산 상공계의 진정·한국 민족계의 통상 발언권 요구와 한 줄에 놓임**([[연방_외교]]) — 일본 문제가 한국 정치의 간접 변수로 재등장하는 구조 |
| 어업 | 동해 어장 마찰 — 극동·한국의 수산과 겹치는 바다([[한국의_연방_풍경_1925]] §5) |
| 공작망 | 휴면 — 1917년 노출 이후 재가동 흔적 없음([[일본의_조선_공작망]]). 다만 명부는 어딘가에 남아 있다 |
| 영일 관계 | 형해화된 동맹 문서는 대전 종전과 함께 사실상 소멸 — 영국의 재접근 카드로도 값이 떨어짐 |

## 4. 연혁 (1905~1925)

| 연도 | 사실 |
|---|---|
| 1905 | 패전 — 하얼빈 조약. 극동 이권 상실·배상 개시 |
| 1915 | 배상 완납 — 대일 지렛대의 소멸(1기 canon) |
| 1914~18 | 대전 중립 — 제한적 전쟁 경기, 도약 없음 |
| 1917 | 조선 공작 노출 — 공작망 휴면기 진입 |
| 1919 | 한국의 연방 편입을 통고받음 — 항의 없이 접수(개입 명분·수단 부재) |
| 1920s | 정당 내각기 — 통상 확대 교섭 반복, 성과는 제한적 |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| 통상 확대 교섭 — 관세·항로·영사 문제 | 일본 ↔ 연방 외무부 | 단속적 교섭 |
| 동해 어업 분쟁 | 일본 어민 ↔ 극동·한국 수산 | 산발 |
| 간도 조선인에 대한 접근 — 수복파의 관심선 | 음지 | 휴면([[중국과_만주_1925]]) |

〔편집 메타 OOC〕 설계 축 = "도약 없는 1920년대": 실제사 일본의 대전 특수(수출 급증·채무국→채권국 전환)는 교전국 수요와 아시아 시장 공백의 산물이라, 중립·무식민지의 본작 일본에는 그 동력이 없다 — 인구압·시장 갈증이 남고, 그것이 두 노선의 토양. 패전이 군부 위신을 꺾어 정당 정치가 원역사보다 이르고 강하다는 설계는 다이쇼 데모크라시의 강화판. 가드레일: 일본은 악마도 희화도 아니고 **갈증을 가진 이웃** — 수복 의지는 잠재 위협으로만(1기 canon 유지), 재점화 여부는 이 위키가 정하지 않는다. 쌀 소동은 원역사(1918)의 유사 사건 차용 가능(전쟁 인플레가 아니라 흉작·투기 요인으로).
