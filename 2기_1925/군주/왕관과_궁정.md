# 왕관과 궁정

## 1. 개요

황제는 연방의 원수이며 국가 통합의 상징이다(헌장 제3조). 대권은 **열거된 것에 한하고**(제22조), 모든 국사 행위는 부서를 요한다(제4조). 재위 [[니콜라이_2세]], 거처는 페테르부르크 겨울궁전 — 연방 수도가 아닌 도시다.

궁정은 국가 기구가 아니다. **궁내성은 내각 밖의 기관**이고, 그 살림은 국고가 아니라 정액 황실비로 돈다.

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **대권 4종** | 서훈·영전(제18조) / 사면·감형·복권(제19조) / 명목 최고사령관(제20조) / 두마 개회·국가 의례 주재(제21조) |
| **부서** | 국사 행위 전부 — 서훈·사면장에도 관계 대신의 부서가 붙는다(제4조) |
| **계승** | 로마노프가의 법통(제1조) — 가법(家法)에 따른 남계 장자 상속. 황태자 알렉세이 |
| **황실비** | **연 1,800만 루블, 10년 정액**(부칙 제5항) — 두마 의결 없이 고정, 1929년 만료 |
| **황실령** | 왕조 세습 재산(영지·궁전)은 사유로 존속 — 그 수입은 황실비 밖, 관리는 궁내성 |
| **궁내성** | 각외(閣外) 기관 — 행정 8부에 속하지 않는다([[연방_내각]]). 소관: 궁정 살림·전례·황실령·13칭호 대관 의례 |
| **교회 지위** | 1923년 교회 자치법 이후 교회 통치 관여 없음 — 정교회의 **수위 신자**라는 의례적 지위만 |

## 3. 대권의 운영

| 대권 | 실무 절차 |
|---|---|
| 서훈 | 명단은 궁내성 전례부가 작성, 내각이 부서 — 훈장 서열·수여식은 궁정 소관 |
| 사면 | 법무부 상신 → 재가. 정기 사면은 대관·성탄 관례 |
| 두마 개회 | **매년 10월 모스크바 행차** — 개회 칙어는 내각이 기초하고 총리가 부서 |
| 군 의례 | 명목 최고사령관(지휘·운용은 법률이 정하는 기관 — 제20조). 열병·군기 수여·서열의 정점. 근위연대는 연방군 편제로 의장 임무 |
| 구성국 의례 | 13칭호의 대관은 한 번의 대관식으로 아울러 받는다(제3조). 구성국 법률 재가는 기일부 — 침묵은 재가([[구성국_정부_구성]]) |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1919 | 헌장 — 대권 열거주의·황실비 정액·왕조 조항 개정 불가(제25조) |
| 1920 | 첫 모스크바 개회 행차 · 궁내성을 각외 기관으로 재편(구 궁정 부처의 국가 기능 이관) |
| 1923 | **「교회 자치법」 무재가 발효** — 성무원에 대한 국가 감독 종료. 재가 기일 30일이 서명 없이 만료된 최초의 법률([[국가헌장_1919]]) |
| 1924 | 정교회 공의회 — **총대주교 선출**(1721년 이래 공석의 복원). 차르는 축하 서한을 보냈고 참석하지 않았다 |
| 1925 | 재위 31년차 |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| 황실비 정액 갱신 | 궁내성 ↔ 내각·두마 | **1929 만료** — 전후 인플레로 실질 가치 감소 지속 |
| 황실령 재산의 과세 지위 (사유라면 구성국 직접세 대상인가) | 궁내성 ↔ 러시아 정부 | 미해결 |

## 숫자

| 항목 | 값 |
|---|---|
| 황실비 | 연 1,800만 루블 (1919~29 정액) |
| 궁내성 | 각외 기관 — 정원·조직은 황실비 한도 내 자율 |
| 무재가 발효 | 1923년 1회 (교회 자치법) |

---

〔편집 메타 OOC〕 계승 = 파벨 1세 계승법(남계 장자) 준용 — 왕조 가법은 헌장 밖 존속. 교회 준거 = 1721 표트르 영성규정 체제(성무원+오버프로쿠라토르 = 국가의 교회 소유)와 원역사 1917 총대주교제 복원(고증 §ⓘ: 왕관이 비면 교회는 저항하지 않고 제 몫을 청구한다) — 본작은 그 청구가 혁명이 아니라 **법률과 재가 기일**로 처리된 세계. 무재가 발효가 하필 이 법인 이유: 기름부음 받은 정교 군주는 교회를 놓는 문서에 이름을 얹을 수 없고, 시계가 대신 서명했다. 알렉세이는 생존(실존 인물 원역사 운명 복제 금지, [[_고증_바이블]] §ⓓ). 황실령 존속 = 황실비 정액 거래의 짝(사유 재산은 건드리지 않는 대신 국고 지원은 고정).
