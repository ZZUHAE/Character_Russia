# 사회 기본 법제

## 1. 개요

새 체제가 사회에 깐 법률은 넷이다 — 출판법·결사법(1920), 신분 특권 정리법(1921), 교회 자치법(1923). 나머지 큰 영역(교육·토지·노동 규제)은 구성국 잔여 사항이라 **연방 법률 자체가 없다.**

## 2. 조문·규정 (골자)

| 법률 | 내용 |
|---|---|
| **「출판법」(1920)** | 사전 검열 폐지. 신문·출판은 **등록제** — 발행인 등록만으로 창간, 책임은 사후에 법원에서(명예훼손·기밀 누설). 전시 검열 조항 실효 |
| **「결사법」(1920)** | 결사·집회 등록제 — 정당·노동조합·협회는 등록으로 법인격. 무장 결사만 금지 |
| **「신분 특권 정리법」(1921)** | **신분 대장(соловие) 폐지** — 출생 신분의 법적 효력 종료. 귀족·명예시민 등 칭호와 문장은 **명예로서 존속**(세습 가능), 조세·재판·임용상 특권은 폐지 |
| **「교회 자치법」(1923)** | 성무원에 대한 국가 감독 종료 — 교회는 공의회로 자치([[왕관과_궁정]]). 비정교 신앙의 관용 확대 — 개종 제한 철폐 |
| **교육** | 연방 법률 없음 — 구성국 소관(유보권 지형: [[연방_구성국_일람]]). 총독주만 내무부 학무국 관할([[연방_권한_분장]]) |
| **토지** | 연방 법률 없음 — 구성국 소관. 러시아 의회에 법안 계류([[러시아_구성국]]) |
| **노동** | 공장 규제·노동 시간은 구성국 소관. 1906년 산업동원 기본법 계열의 연방 법령만 존속(부칙 제9항) |

## 3. 구성·조직

| 영역 | 관할 |
|---|---|
| 출판 등록·법인 등록 | 구성국 내무 당국 (연방 기준법 + 구성국 시행) |
| 명예 칭호·문장 | 궁내성 전례부([[왕관과_궁정]]) — 국가 특권과 절연된 채 관리 |
| 교회 | 총대주교·공의회 (1924~) — 국가 기구 아님 |
| 학교 | 구성국 교육 당국 / 총독주는 내무부 학무국 |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1920 | 출판법·결사법 — 사전 검열 폐지, 정당·노조 합법화. 1기의 이중 검열 창구 해체 |
| 1921 | 신분 특권 정리법 — 신분 대장 폐지. 선거인 명부(1919 선거법의 신분 불문 원칙)와 법제 정합 완성 |
| 1923 | 교회 자치법 무재가 발효 |
| 1924 | 공의회 — 총대주교 선출. 첫 정당 선거([[정당_체계]])가 출판·결사법 위에서 치러짐 |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| 명예훼손 소송의 남용 (사후 책임제의 운용) | 언론 ↔ 법원 | 판례 형성 중 |
| 귀족 단체(귀족회)의 법적 지위 — 신분 기관인가 임의 결사인가 | 귀족회 ↔ 구성국 정부 | 등록 전환 진행 |
| 교회 재산(수도원령·교회 토지)의 과세 지위 | 교회 ↔ 구성국 재정 당국 | 미해결 |

〔편집 메타 OOC〕 얇은 목록 자체가 설계 — 사회 영역 대부분이 구성국 잔여라 연방의 사회 입법은 "전국 공통이어야만 하는 것"(표현·결사·신분·교회) 넷으로 끝난다. 출판 사후 책임제 = 동시대 서구 표준. 신분 정리 준거 = 1기 canon "신분제는 교착으로 못 건드림" → 교착이 풀린 뒤(1919) 첫 회기들이 처리한 순서. 노동 규제를 구성국에 둔 것은 전속 목록에 없다는 법리의 귀결(공업 구성국별 기준 차이는 배경 사실로 열림). 1기 canon(신분질서·검열·정교회 노트)은 동결 — 이 노트가 1925년 상태를 서술.
