# 모스크바 연방 대학 (와 연방 기술 대학)

## 1. 개요

교육은 구성국 소관이고 연방에 교육부는 없다([[연방_권한_분장]]). 그 원칙의 예외가 **연방 직할 고등교육기관 둘** — 수도 구역의 인재 양성 기관 논리로 「연방 대학령」(1920)이 세운 **모스크바 연방 대학**(구 제국 모스크바 대학, 1755)과, 「기술 대학령」(1922)이 인수·확장한 **연방 기술 대학**(구 황립 기술학교)이다. 러시아의 다른 대학들(페테르부르크 대학 등)은 러시아 구성국 소관이다.

연방 대학은 열세 구성국의 문관·법률가·경제가를, 기술 대학은 철도·전력·야금의 기사를 기른다. 두 학교의 구성국 학생 모집이 1925년 **공개 경쟁 시험**으로 전환되며 지방 인가 학교 졸업자에게 문이 넓어졌다([[한국_학제_1925]]).

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **설치** | 「연방 대학령」(1920) · 「기술 대학령」(1922) — 연방 직할 법인, 예산은 연방 세출 |
| **자치** | 총장은 교수회 선출, 학칙은 평의회 의결(대학령이 자치 학칙 부여) |
| **입학** | 중등 졸업 + 입학 전형. **구성국 학생 모집 = 공개 경쟁 시험**(1925 전환 — 각국 시험장·각국 정원, 한국 20) |
| **여학생** | **1920 학칙부터 입학 무제한** — 별도 조항 없음(제한 조항이 없는 것이 조항) |
| **학년도** | 9월 1일 개시~5월 종료(러시아권 1921 학년도 통일령 — [[러시아_구성국]]) · 2학기제·성탄 방학 |
| **준비 학기** | 3월 1일 개강~8월 — **구성국 신입의 어학·강독 과정**(1921 관비 파견 개시와 함께 설치). 재적은 정식 학생 |
| **시험** | 학년말 구술시험(5월 시험 기간 — 교수 앞 문답) · 세미나·강독 중심 학사 |
| **학비** | 자비생 연납 · 관비생 면제+학자금(각국 협약 — [[한국_학제_1925]]) |

## 3. 구성·조직

**모스크바 연방 대학** — 모호바야 거리(크렘린·수도 구역 코앞. 경제학부 강의실 창에서 의사당 지붕이 보인다):

| 학부 | 내용 |
|---|---|
| 법학부 | 국법·조약법·사법 — 문관시험·법조의 본류 |
| **경제학부** | **1920 개편 신설** — 구 법학부 정치경제 강좌의 독립. 정치경제·통계·재정. 통계국·재무부 실습 연계 |
| 역사문헌학부 | 문헌·사학·어문 |
| 물리수학부 | 수학·물리·화학·천문 |
| 의학부 | 부속 병원 |

**연방 기술 대학** — 동쪽 레포르토보(공장 지대와 붙어 있다):

| 항목 | 내용 |
|---|---|
| 과 | 기계·전기·철도·야금·건축 |
| **1922~ 대규모 확장** | 신 실험 공장·실습장·장학 — [[동방_개발_계획]]·전력·철도의 기사 수요가 예산 논거. 연방 세출의 인재 양성 항목 최대 수혜 |
| 접속 | **철도학당 계통의 상급 진학처**([[한국의_연방_풍경_1925]]) · 졸업생은 철도·개발 현장으로 |

**구성국 학생의 세계**: 동향회(землячество)들 — 조선·폴란드·핀란드·캅카스·투르케스탄 학생회가 하숙 알선·헌 교재·명절 밥을 돌린다. 기숙사는 없다 — 하숙의 도시([[연방_수도_모스크바]]). 관비생의 전공 배분은 각국 수요를 따르며, **공학 몫이 가장 크다**(개발 인력 — 한국 관비 20 중에도 기술 대학 몫이 다수).

**진로 파이프**: 연방 대학 → **통일 문관시험**([[연방_행정과_문관제]] — 연방 관료층의 러시아어권 편중이 여기서 재생산된다) · 통계국·재무부 조사 실습 / 기술 대학 → 철도·전력·개발 청부.

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1755 | 제국 모스크바 대학 개교(모호바야) |
| 1830 | 황립 기술학교 개교(레포르토보) |
| 1920 | 「연방 대학령」 — 연방 인수·개편. 경제학부 신설·여학생 입학 무제한 학칙·자치 학칙 |
| 1921 | 준비 학기 설치(구성국 관비 파견 개시와 함께) · 러시아권 학년도 통일(9월) |
| 1922 | 「기술 대학령」 — 황립 기술학교를 연방 기술 대학으로 인수·**대규모 확장 개시** |
| 1925 | 구성국 학생 모집 공개 경쟁 시험 전환 — 별도 모집(고등여자과정 한정) 폐지, 같은 시험·같은 정원 |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| 구성국 몫 정원 배분 기준 — 인구 비례 요구 | 구성국들 ↔ 대학·관방 | 계류 — 선거구 재획정과 같은 산수, **1929** 언저리 |
| 구성국 어문 강좌 개설 요구(수업어는 러시아어 단일) | 구성국 학생회들 ↔ 평의회 | 연례 청원 |
| 자치 학칙의 범위(직할 법인 vs 교수회) | 관방 ↔ 평의회 | 잠복 |

〔편집 메타 OOC〕 준거: 제국 모스크바 대학 1913 재학 ~1만(러시아 최대)·황립 모스크바 기술학교(1830, 원역사 바우만 — 당대 러시아 최고 공학교)·러시아 학제에서 공학은 대학 밖 별도 전문학교 체계(그래서 공학부 신설이 아니라 별도 직할 대학). 경제학부 독립 = 원역사에선 법학부 안 정치경제 강좌 — 1920 개편 신설은 연방 행정 인재 수요의 마커(모스크바 상업전문(1907 실존)이 수요의 실증). 여학생 무제한 = 원역사 제정 대학은 여성 미입학(게리에 과정 등 별도)이었으나 이 세계 1920 개편이 지움 — 닫혀 있던 것은 한국 관비 선발의 별도 모집이었고 1925 폐지([[한국_학제_1925]]). 구술시험·동향회·하숙 = 제정기 대학 문화 실재. 기술 대학 대규모 투자(2026-08-11 사용자 방향) = 동방 개발·전력·철도 인재 수요와 연동, 공학 몫 최대 = 이화(경제)가 유학생 사회 안 소수파가 되는 구조. 수치는 기준계.
