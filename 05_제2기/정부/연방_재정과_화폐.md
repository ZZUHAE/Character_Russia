# 연방 재정과 화폐

## 1. 개요

연방은 간접세로 살고([[연방_권한_분장]]), 화폐는 **하나 반**이다 — 루블이 등뼈이고, 핀란드 마르카와 한국 원(圓)이 유보 화폐로 남아 있되 루블 준비금을 담보로 발행된다. 금태환은 전쟁 중에 멎어 아직 돌아오지 않았고, 그 재개 여부가 1925년 재정의 최대 쟁점이다.

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **발권** | 연방 국립은행 독점 — 본점 페테르부르크([[연방_수도_모스크바]]). 재무부는 모스크바 |
| **유보 화폐 2종** | 핀란드 마르카 = 핀란드 은행 / 한국 원 = 1920~24 **연방 국립은행 한성 지부의 위탁 발행**(한국 정부 명의) → 1923 「한국은행법」 → **1924 한국은행(탁지부 감독) 발권 인수** — 모두 **발행고만큼 루블·금 준비금을 적립**하고 루블 고정 환율을 유지한다 |
| **결제 관행** | 연방 납부(관세·분담금)·철도·연방 조달·개발 공채는 루블 표시. 유보 화폐는 자국 내 유통 |
| **외채** | 전시 채무의 당사자 = 연방. 채권단과 상환 연장 협정 체결(1920년대 초) — 탕감 없음, 기한 연장·이자 조정 |
| **개발 재원** | 동방 개발은 세출이 아니라 **연방 개발 공채** — 페테르부르크 거래소 발행, 철도·항만 수입으로 상환([[동방_개발_계획]]) |
| **세원·분담금** | [[연방_권한_분장]] §2 — 관세·소비세·철도우편 + 인구 비례 분담금 |

## 3. 안정화의 계단 (경과)

| 연도 | 사실 |
|---|---|
| 1916 | **금태환 정지** — 전비 발권 확대 |
| 1918 | 종전 시점 물가 = 전전의 약 3배 |
| 1919~21 | 전후 물가 상승 지속 — 동원 해제·재건 지출. 1923 분담금 사정 파동의 원인([[연방_권한_분장]]) |
| 1922 | 재정 균형 회복 — 관세·소비세 정상화 + 감군의 배당([[연방군]]) |
| 1924 | **화폐 개혁 — 연방 루블(聯邦 루블).** 「화폐 개혁법」 명칭 조항으로 단위명에 국체를 새김. 구권 교환·금 준비금 적립·금환본위 목표 선언. 시중 호칭은 그대로 "루블" |
| 1925 | **금태환 재개 논쟁** — 그해 4월 영국의 금본위 복귀가 압력. 재개론 = 금융가·채권단 신용 / 유보론 = 수출업·농민동맹·개발파 |

## 4. 구성·조직

| 기관 | 소재 | 비고 |
|---|---|---|
| 재무부 | 모스크바 | 행정 8부([[연방_내각]]) |
| 연방 국립은행 | 페테르부르크 | 발권·국고 — 재무부와 밤차 12시간 |
| 핀란드 은행 · 한국은행 | 헬싱포르스 · 한성 | 유보 화폐 발행(한국은행은 1923 설립·1924 발권 인수) — 준비금 계정은 연방 국립은행에 |
| 연방 국립은행 한성 지부 | 한성 | 구 한러은행 국고·채권 업무 인수(1920) · 원권 위탁 발행(1920~24) · 분담금 수납 |
| 거래소 | 페테르부르크 | 공채·개발 공채 시장 |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| **금태환 재개** | 재무부 내 재개론 ↔ 두마 유보론 | 계류 — 결론 없음 |
| **화폐 유보 회수** — 재무부, 1929 유보 조약 갱신 의제서에 등재 준비. 논거 = "연방의 돈에는 연방의 이름이 있다" | 재무부 ↔ 핀란드·한국 | **1929** — 핀란드의 논거는 자국 화폐 60년의 역사, 한국의 논거는 편입의 값 |
| 개발 공채 인수단의 이해 문제 — 인수 금융과 수주 기업의 계열 중복 | 두마 예산위 ↔ 재무부 | 질의 계류([[동방_개발_계획]]) |
| 분담금 산식(인구 ↔ 소득 비례) | 구성국들 | **1929 사정**([[연방_권한_분장]]) |

## 숫자 (기준계)

| 항목 | 값 |
|---|---|
| 외채 잔액 | ~60억 루블 (전전 ~40억) |
| 채무 상환 | 연방 세출의 ~15% |
| 물가 (1918/1914) | ~3배 |
| 한국 구 차관 소각액 | 3,400만 루블 상당 — 외채 잔액의 0.06%([[한국_편입_경과_1918_1920]]) |

〔편집 메타 OOC〕 준거 = 영국 1925.4 금본위 복귀(본작 1925년의 재개 논쟁은 이 시대 라임 그대로)·독일 1871→1876 화폐 통일(연합 5년 만에 마르크 단일화 — 재무부 통일론의 전거)·**라이히스마르크 1924**(안정화 화폐에 국체의 이름을 새기는 그 해의 문법 — '연방 루블' 명명의 원형. 부수 회색: 루블은 본디 러시아의 돈인데 연방이 이름을 가져감 — 러시아 민족파의 낮은 불평)·핀란드 마르카(1860 도입, 제정 아래서 실제로 60년 존속 — 유보 화폐가 발명이 아니라 역사적 사실이라는 근거)·스코틀랜드 은행권(연합 후 자체 지폐 존속의 병행 선례). 1기 미결 Q12(금본위 이탈)의 회수: 1915 유지 → 1916 정지 확정 → 1925 재개 논쟁으로 세대 교체. 화폐 통일 문제의 실질 = 페그와 준비금 제도로 이미 반쯤 통일("법적으론 세 화폐, 경제적으론 한 화폐") — 연방의 방침은 강제가 아니라 루블 결제 영역 확대라는 습관의 전략이며, 이는 문서상 사실(결제 관행 행)로만 적었다. 숫자는 전부 기준계.
