# 연방 내각

## 1. 개요

연방의 행정부. **총리는 두마의 신임으로 정하고**(헌장 제12조), 내각은 국정 전반을 통할하며 두마에 책임을 진다(제14조). 조직·직무·불신임 절차는 「내각법」(1920)이 정한다(제17조).

행정 각부는 **여덟**이고, 그 목록은 연방 전속 사항과 1:1로 대응한다. 교육부도 농무부도 없다 — 교육과 토지는 구성국의 것이라 연방에 그 부처가 존재하지 않는다.

## 2. 조문·규정 (골자) — 「내각법」(1920)

| 항목 | 내용 |
|---|---|
| **구성** | 총리 + 각부 대신. 각의(閣議) = 의결 기관, 총리 주재·각료 과반 출석 |
| **총리 선임** | 두마 재적 과반의 신임 의결 → 황제 임명(임명장 부서 = 전임 총리) — [[두마_조직과_운영]] |
| **각료** | 총리 제청으로 임명·해임(헌장 제13조). 두마 의원 겸직 허용, 상원 의원·러시아 각료 겸직 금지 |
| **불신임 발의** | **재적 4분의 1(131명) 연서** |
| **냉각** | 발의 후 **닷새 뒤 표결** |
| **가결** | **재적 과반(263)** → 내각 총사퇴. 부결된 불신임안은 같은 회기 재발의 불가 |
| **직무 수행** | 총사퇴한 내각은 **후임 총리 신임까지 직무를 수행**한다 |
| **정부 교체기** | 총선 후 새 두마 개원 시 내각은 총사퇴하고 신임 절차를 다시 밟는다 |
| **부서 배분** | 국사 행위 부서(제4조) — 국정 전반·임명은 총리, 소관 사항은 관계 대신 |
| **총리 유고** | 대행 = 각의가 미리 정한 순위에 따름 |

〔편집 메타 OOC〕 불신임 감속 설계 = 동시대 표준(단순 과반 불신임)이 프랑스 3공 내각 회전문(평균 수명 8개월)을 낳은 것의 보정 — 단 건설적 불신임은 실제사 1949 서독 발명이라 채택하지 않고, 높은 문턱(재적 과반) + 발의 연서 + 냉각 + 재발의 금지의 조합으로 같은 효과를 시대 정합적으로 냄. 해산 제도 부재(P3)와 세트: 무너뜨린 다수가 같은 의석에서 후임을 세워야 한다. 8부 목록은 연방 전속 사항의 사상(寫像)이라 권한 분장이 바뀌지 않는 한 늘지 않는 구조. 겸직 규정: 두마 의원 겸직 허용 = 의원내각제 표준, 상원 금지 = 구성국의 원 독립성.
