# 연방 행정과 문관제

## 1. 개요

연방의 수반 구조는 둘뿐이다 — **원수는 차르**(의례, 헌장 제3조), **정부 수반은 총리**(두마 신임, 제12조). 대통령격의 제3의 자리는 없다.

총리는 부처를 갖지 않는 대신 **소형 관방 3국**을 손발로 가진다. 연방 관리는 **통일 문관시험** 하나로 뽑고, 시험 없는 하급 현장직(고원)이 그 아래에 있다.

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **총리 관방** | 각의 의사·문서·부처 간 조정 — 소형 기구 |
| **법제국** | 정부 법안의 사전 심사 — 모든 정부 제출 법안이 두마에 가기 전 거치는 관문 |
| **통계국** | 인구·세입 통계 — **분담금 사정(5년)·선거구 재검토(10년)의 분모를 만드는 곳** |
| **문관시험** | 연 1회 공개경쟁 — **시험어 러시아어, 성적순, 구성국 안배 없음.** 합격 = 관등 임용(1기 14등관제 승계) |
| **기술직** | 철도·체신·세관 기술직은 별도 기술시험 (같은 원칙) |
| **정치직·직업직** | 대신·차관 = 정치직(내각과 진퇴). 국장 이하 = 직업 문관(신분 보장) |
| **고원(雇員)** | 시험 없이 **현지 채용**되는 하급 직원 — 역부·전신수·세관 창고계 등. 문관이 아니며 관등이 없다 |

## 3. 구성·조직 (8부 내부 골격)

| 부 | 주요 국(局) |
|---|---|
| 외무부 | 정무국 · 조약국 · 영사국 |
| 군무부 | 군정 각국 + 참모본부(군령 — 제20조의 "법률이 정하는 기관") |
| 재무부 | 국고국 · 세관총국 · 화폐국(국립은행 감독) |
| 교통부 | 철도총국 · 건설국 |
| 체신부 | 우편총국 · 전신국 |
| 내무부 | 시민권·선거국 · 총독주국 · 학무국(총독주 교육) · 수도 관리청 |
| 법무부 | 법무국 · 대심원 검사국 |
| 상공부 | 통상국 · 전매국 · 협의회 사무국 |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1920 | 내각법과 함께 관방·법제국 설치 |

| 1923 | 첫 사정 파동에서 통계국 기준 연도 문제가 드러남([[연방_권한_분장]]) |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| 고원의 문관 전환 경로 (근속 고원의 무시험 승진 요구) | 고원층 ↔ 각부 | 법 개정 논의 |
| 기술직 부족 (철도·체신 확장 속도 대비) | 교통부·체신부 ↔ 재무부 | 증원 예산 다툼 |

## 숫자 (기준계)

| 항목 | 값 |
|---|---|
| 문관시험 | 연 1회 · 러시아어 · 성적순 |
| 관등 | 14등관제 승계 |
| 연방 조직의 인적 구성 | 문관(시험) + 고원(현지 채용)의 이중 구조 |

---

〔편집 메타 OOC〕 임용 준거 = 영국 1870 공개경쟁시험·독일/러시아 제정 관등 시험 — 통일 시험·성적순이 1925 시대 표준이고 구성국 쿼터는 20세기 후반 물건이라 미채택. 기능적 귀결(규정 없이 인구 구조가 만드는 것): 시험어가 러시아어라 연방 관료층은 러시아어권 편중이 되고, 비러시아계 구성국 인재는 자국 정부·의회 경로로 성장하는 **이중 경력 구조**가 자연 발생 — 한국의 과거 자격 유보는 한국 정부 임용에만 효력이 있고 연방직의 문은 러시아어로 되어 있다([[한국_왕국]]). 고원 제도 = 전국 조직(철도·세관)이 현지 인력 없이 못 도는 현실의 법제화. 관방 3국 소형 = "얇은 연방" 원칙의 행정부판.
