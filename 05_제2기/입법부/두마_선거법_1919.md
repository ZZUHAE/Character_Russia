# 두마 선거법 (1919)

## 1. 개요

[[국가헌장_1919]] 제11조가 미룬 것을 받아 같은 해 제정된 법. 선거권은 **직접세를 납부하는 가구의 성년 전원**(25세 이상, 남녀 불문)과 **등록 사업장의 상용 임금노동자**에게 있다. 전 구성국을 소선거구로 나눠 **직접·비밀·단순다수**로 하원 524석을 뽑는다. 신분을 묻지 않고 표의 무게를 달리하지 않는다.

두마는 구성국이 아니라 **인구를 대표한다** — 구성국을 대표하는 것은 상원이다([[제국의_국체와_연방_구조]]).

## 2. 조문·규정 (골자)

| 장 | 내용 |
|---|---|
| **선거권** | 25세 이상 제국 시민 중 ⓐ직접세(토지세·가옥세·영업세·젬스트보 부과금)를 납부하는 **가구의 성년 구성원 전원** ⓑ등록 사업장의 **상용 임금노동자**. 성별을 묻지 않는다 |
| **제외** | 직접세 가구에 속하지 않고 상용 고용도 없는 자(머슴·날품·부랑노동) · 금치산·수형자. 현역 군인은 재적 선거구 우편 투표 |
| **피선거권** | 30세 이상 선거권자. 관리·현역 군인·성직자는 겸직 금지 |
| **선거구** | 구성국 안에서 획정하는 소선거구. **각 도(губерния) 최소 2석**, 잔여 의석 인구비례. 인구 10만 이상 도시는 별도 선거구 |
| **정수** | **524석** |
| **투표** | 직접·비밀·단독 투표, 개표는 선거구별 공개. 투표일은 내무부가 도별 지정 — 전국 동일일자를 요하지 않는다 |
| **당선** | 단순다수 1인 선출. 동수일 때 연장자 |
| **명부** | 세무·젬스트보 대장 + 마을 호적으로 작성. 임금노동자는 고용주의 재직 증명으로 등재 |
| **특례** | 선거인 자격을 유보한 구성국은 자체 법의 자격으로 두마 의원을 뽑는다 — 현재 **핀란드** 한 곳(남녀 보통선거) |

## 3. 부칙·경과규정

1. 제1차 선거의 유권자 명부는 1919년도 세무·젬스트보 대장으로 갈음한다.
2. 제1차 선거의 투표 기간은 **3주를 넘지 아니한다** (상한).
3. 동원 해제 중인 군인은 1920년에 한하여 부대 소재지에서 투표, 표는 재적 선거구로 이송.
4. 자격 유보 구성국에서도 선거구 획정·투표 방식·정수 배분은 이 법에 따른다.
5. **선거구 획정은 10년마다 재검토한다** → 첫 재검토 **1929년**.

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1919 | 제정. 비례대표안 부결(명부를 낼 정당 부재), 소선거구 단순다수 채택 |
| 1920 | 제1차 총선 — 도별 순차 투표 3주, 무소속·명망가 다수 |
| 1920~ | "상용(常用)" 정의 소송 — 임금노동자 등재 기준 판결이 도마다 갈림, 1924년까지 미통일 |
| 1923 | 도시 선출 의원들의 조기 재획정 법안 — 하원 통과, **상원 지연**(두 방이 정면으로 맞선 첫 사례) |
| 1924 | 제2차 총선 — 첫 정당 선거 |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| 선거구 재획정 (도농 격차 17만/석 ↔ 40만+/석) | 도시 선거구 ↔ 변경 도 | 부칙 제5항 — **1929** |
| "상용" 정의 통일 | 노동자 ↔ 고용주·도 법원 | 판례 불일치 지속 |
| 선거인 자격 확대 (핀란드 격차 준거) | 확대론 ↔ 내무부 | 요구 계속 |

## 숫자

1915년 분모([[제국_인구와_민족_구성]]·[[거시_회계_시트]])에서 파생한 기준계.

| 항목 | 1925년 추정 | 산출 |
|---|---|---|
| 총인구 | ~2억 1,200만 | 13개 구성국 합계([[연방_구성국_일람]]) |
| 25세 이상 | ~8,060만 (38%) | |
| **유권자** | **~5,640만** | 성인의 약 70% (핀란드만 ~100%) |
| 정수 | **524석** | 90개 도 × 2석 = 180 + 인구비례 344 = **524** ✅ |
| 평균 | 인구 40만 / 유권자 11만 당 1석 | 격차: 변경 17만/석 ↔ 대도시 40만+/석 |

구성국별 의석(개략): 러시아 ~210 · 우크라이나 ~79 · **한국 ~42** · 폴란드 ~35 · 시베리아 ~32 · 투르케스탄 ~32 · 백러시아 ~24 · 발트 ~17 · 극동 ~14 · 핀란드 ~11 · 조지아 ~9 · 아제르바이잔 ~8 · 아르메니아 ~6.

〔편집 메타 OOC〕 정수 524 = 1907년 감축 이전 정수의 복원("늘리는 게 아니라 돌려놓는 것" 프레임 — 본문에는 옛 제도명을 부르지 않는다, MOC 서술 원칙). 남녀 불문은 원칙이 아니라 가구 과세의 부산물 + 핀란드 1906 선례가 논거였다는 설정. 임금노동자 조항의 논거는 전시 기여([[제국_산업동원_협의회]]). 검산 준거: 원역사 1917 제헌의회 선거(유권자 7,170만·투표 64%·사흘 투표)가 광대한 영토 직접선거의 물리적 실증. 수치는 기준계.
