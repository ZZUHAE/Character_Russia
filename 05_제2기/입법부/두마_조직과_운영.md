# 두마 — 조직과 운영

## 1. 개요

하원 524석([[두마_선거법_1919]])의 조직과 의사 절차. 「두마 조직법」(1920)은 첫 두마가 스스로 제정했다. 임기는 **4년 고정**이며 **해산 제도가 없다** — 헌장은 해산권을 누구에게도 적지 않았고, 적히지 않은 권한은 존재하지 않는다(제22조의 문법). 총선은 1920년부터 4년마다 돌아온다.

## 2. 조문·규정 (골자) — 「두마 조직법」(1920)

| 항목 | 내용 |
|---|---|
| **임기** | 4년 고정. 해산·조기 총선 제도 없음 |
| **회기** | 연 1회 정기 회기 — 10월 개원, 이듬해 6월 폐회. 소집·개회 기일은 법정이며 누구도 미룰 수 없다(헌장 제10조). 개회는 황제(제21조) |
| **의장단** | 의장 1·부의장 2 — 재적 과반 선출, 임기는 의회 임기와 같음 |
| **위원회** | 상임위원회 — 예산·법제·외무·군무·구성국 사무 등. 의석 비례 배분 |
| **교섭단체** | 15석 이상 등록 — 위원회 배분·발언 순서의 단위([[정당_체계]]) |
| **입법** | 3독회제 — 제1독회 대체 토론 · 제2독회 축조 심의(위원회) · 제3독회 확정 표결 |
| **법률 성립** | 두마 의결 → [[국가평의회|상원]] 이송(재의 요구권, 30일) → 재가(30일 기일부, 헌장 제9조) → 관보 공포 |
| **총리 신임** | **재적 과반의 신임 의결** → 황제 임명(임명장 부서 = 전임 총리). 불신임도 재적 과반 — 절차 세부는 내각법(→ P4) |
| **예산** | 회계연도 예산은 법률로(헌장 제15조) — 예산위원회 선심의 |
| **특권** | 회기 중 불체포(현행범 제외)·원내 발언 면책 |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1920 | 첫 두마 모스크바 개원 — 첫 회기에서 「두마 조직법」 제정, 총리 신임 절차 첫 적용 |
| 1923 | 조기 재획정 법안 — 두마 통과, 상원 재의 요구, 재의결 정족 미달로 폐기 |
| 1924 | 제2차 총선(첫 정당 선거) — 두 번째 두마 개원 |

---

〔편집 메타 OOC〕 해산 제도 부재 = 열거주의(헌장 제22조)의 일관 적용 — 왕관에도 내각에도 해산권 조문이 없으므로 존재하지 않으며, 그 결과 불신임이 나도 같은 의석에서 새 정부를 세워야 하고 선거는 4년 시계로만 온다. 회기 10월~6월은 제정기 두마·유럽 의회 표준 준용. 3독회·교섭단체·위원회는 동시대 대륙 의회 표준. 총리 임명장 부서 = 전임 총리는 부서 원칙(제4조)의 순환 해법(헝가리·의원내각제 관행 준용).
