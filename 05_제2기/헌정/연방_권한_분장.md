# 연방 권한 분장

## 1. 개요

권한은 **3층**이다 — 연방 전속, 구성국 잔여, 그리고 조약이 전속에 뚫은 유보의 구멍. 재정은 **연방이 간접세로 살고 부족분을 구성국 분담금으로** 메운다. 직접세는 구성국의 것이다. 사법은 두 계단이며, 종심이 어디서 끝나는지는 그 구성국의 사법 유보 여부에 달렸다.

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **연방 전속** | 외교·선전강화·연방군·관세·화폐·연방 철도·우편전신([[국가헌장_조문]] 제5조). 전속 사항에서 연방법은 구성국법에 우선한다 |
| **구성국 잔여** | 위임되지 아니한 전부(제2조) — 교육·사법·치안·보건·토지·지방행정 |
| **유보 예외** | 전속 사항을 의정서가 뚫는다 — 핀란드 관세·우편, 한국·핀란드 화폐([[연방_가입_의정서_일람]]) |
| **연방 세원** | 관세 · 소비세(주세·설탕세·연초세) · 연방 철도·우편전신 수입 |
| **분담금** | 연방 세출 부족분을 구성국이 **인구 비례**로 갹출. 산정 기준은 5년마다 — 다음 사정 **1929** |
| **구성국 세원** | 직접세 전부(토지·가옥·영업세 등). 두마 선거인 명부의 원천이 구성국 직접세 대장([[두마_선거법_1919]]) |
| **사법** | 연방 사항 = **연방 대심원**(모스크바) 종심. 구성국 사항 = 사법 유보국(한국·폴란드·발트·캅카스 3국)은 자국 법원 종심, 그 외는 대심원 상고 가능 |
| **총독주** | 시베리아·극동·투르케스탄 — **잔여권을 연방이 대행하는 구성국.** 승격 = 잔여권 회수 |
| **수반 회의** | 13개 구성국 정부 수반의 연례 회의(조약 갱신 전년은 2회). 헌장 근거 조문 없음 — 의결권·구속력 없음 |

## 3. 구성·조직

| 기관 | 소재 | 비고 |
|---|---|---|
| 연방 대심원 | 모스크바 | 1920 개원 |
| 연방 세관·항만청·철도국 | 각 구성국 소재 | 연방 전속 사항의 현지 실무 기관 — 감독 기관 아님 |
| 수반 회의 | 개최지 구성국 수도 순번 | 자치 구성국 수반 10 + 총독 3 |

구성국 수반: 자치 구성국 10곳은 **자국 의회의 신임으로 서는 수상**(명칭은 각국 전통 — 한국 총리대신 등), 총독주 3곳은 **연방 임명 총독**. 1924년부터 총독주에도 선출 의회가 있으나 행정 수반은 여전히 총독이다.

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1919 | 권한 3층·분담금 구조를 헌장 제5조와 조직법에 규정 |
| 1920 | 연방 대심원 개원(모스크바) |
| 1921 | 첫 수반 회의 — 유보권 조약 갱신 준비 실무 협의로 시작, 이후 연례화 |
| 1923 | **분담금 사정 파동** — 전후 물가로 기준 통계가 어긋나 3개 구성국(러시아 포함) 납부 유예, 상원 조정으로 반년 뒤 타결 |
| 1924 | 총독주 선출 의회 개원 — 행정 수반은 총독 유지 |
| 1925 | 수반 회의에 "동등 지위 선언" 채택안 상정 |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| **"동등 지위 선언" 채택** ("모든 구성국은 지위에서 동등하며 왕관에 대한 공통의 충성으로 결합한다") | 수반 회의(극동·한국 민족계·핀란드 추진) ↔ 연방 정부 | 계류 |
| 화폐 유보 회수 — 재무부의 1929 갱신 의제 준비 | 재무부 ↔ 핀란드·한국 | **1929**([[연방_재정과_화폐]]) |
| 병역 차등의 분담금 반영 요구 ("피의 분담") | 징병 구성국 ↔ 연방 | **1929 사정 합류**([[연방군]]) |
| 총독주 잔여권 회수(승격) — 극동이 선두 | 극동 ↔ 연방 | **1929 이월** |
| 분담금 산식 (인구 비례 ↔ 소득 비례) | 러시아·투르케스탄 ↔ 발트·핀란드 | **1929 사정** |
| 총독주 경과 조치의 종기 — "구성국 의회와 정부가 서기까지"에서 의회는 섰고 정부는 아직 | 총독주 3 ↔ 연방 | 조문 침묵 |

## 침투 실측 — 연방이 일상에 닿는 깊이

연방 전속 사무가 구성국 주민의 일상에 닿는 깊이는 균일하지 않다 — **유보 목록의 반대 상(像)**이다.

| 등급 | 구성국 | 일상에서 만나는 연방 |
|---|---|---|
| 얇음 | 핀란드 | 국경 역뿐 — 관세·우편·화폐·사법 전부 유보. 자기 우표·자기 마르카·자기 법원 |
| 중간 | 한국·폴란드·조지아·발트 | 세관·철도·우체국. 법정과 학교는 자국 것, 화폐는 자국 표시(한국) |
| 깊음 | 우크라이나·백러시아·아제르바이잔·아르메니아 | 위 전부 + 대심원 상고 + 소비세 징수망 |
| 전부 | 총독주 3 | 잔여권까지 연방 대행 — 승격이 유일한 출구 |

전 구성국 공통의 상한: 연방 경찰 없음 · 연방 하급심 없음 · 위헌 심사 없음 · 교육·토지·노동 불간섭(잔여권). **연방은 국경과 동맥(철도·세관·화폐)의 정부이지 일상의 정부가 아니다.**

## 숫자 (기준계)

|---|---|

| 사법 유보국 | 한국·폴란드·발트·조지아·아르메니아·아제르바이잔 |

〔편집 메타 OOC〕 재정 준거 = 독일 제국(관세·소비세 + 구성국 분담금 Matrikularbeiträge, 직접세는 각국) + 미국 1913 이전(연방 세원 = 관세·소비세뿐) — "중앙은 간접세로 살고 직접세는 구성국"이 1914년 이전 연방의 시대 표준. 수반 회의·동등 지위 선언 준거 = 영제국회의·발푸어 선언(1926) — 본작 1925년은 실제 자치령들이 같은 요구를 밀던 시점이라, 자치령 소식(1922 아일랜드 자치령화·1923 캐나다 단독 조약)이 구성국 신문에 실려 in-world 논거로 쓰인다는 설정. 총독주 대행 법리는 극동 학교 관할(기존 canon)의 법적 근거를 소급 부여한 것. 세입 비율·사정 주기는 기준계.
