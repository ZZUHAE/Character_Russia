# 제국의 국체와 연방 구조

## 1. 개요

제국은 **13개 구성국의 연방**이며, 통합의 근거는 민족·언어·종교가 아니라 **왕관 하나**다. 차르는 구성국마다 다른 칭호로 그 군주를 겸하고([[국가헌장_조문]] 제3조), 왕관은 통치하지 않는다(제4조 부서 원칙).

각 구성국은 자체 의회와 정부, 저마다 다른 유보권을 가진다. 연방 수도는 **모스크바**, 왕관·궁정과 러시아 구성국의 수도는 **페테르부르크**다. 1925년은 헌장 6년차, 연방 운영 5년차.

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **구성** | 13개 구성국. 명단·지위·수도·의석은 [[연방_구성국_일람]] |
| **수도** | 연방 수도 모스크바 · 러시아 수도와 궁정은 페테르부르크([[러시아_구성국]]) |
| **왕관** | 차르가 13칭호로 각 구성국 군주 겸위 — 전러시아의 황제, 우크라이나의 대공, 폴란드의 차르, **한국의 왕**, 핀란드의 대공 등([[국가헌장_조문]] 제3조) |
| **구성국 권한** | 자체 의회·정부·법제·행정. 위임되지 아니한 사항은 구성국에(헌장 제2조) |
| **연방 전권** | 외교·선전강화·연방군·관세·화폐·연방 철도·우편전신. 상세: [[연방_권한_분장]] |
| **유보권** | 구성국별 개별 조약, 균일하지 않음 — [[연방_가입_의정서_일람]] |
| **연방 직할** | 바쿠 유전·주요 군항·연방 수도 구역 |
| **상원(국가평의회)** | 구성국별 배정 **124석**, 각 구성국 의회가 선출·개인 표결. 입법권 없음 — 재의 요구·분쟁 조정·개헌 동의([[국가평의회]]) |
| **하원(두마)** | 전 구성국 통합 직선 524석 — 인구를 대표([[두마_선거법_1919]]) |
| **연방 시민권** | 전 구성국 공통. 구성국 간 이동·거주·영업 무제한 |
| **탈퇴** | 조항 없음. 제2조(구성국 명부 포함)는 개정 불가(헌장 제25조) |

## 3. 구성·조직

- 구성국 지위명(왕국·대공국·차르국·공국·총독주)은 **의례 칭호**이며 법적 위계가 아니다 — 법률 통칭은 **구성국**, 실제 차이는 유보권에서 나온다.
- **총독주**(시베리아·극동·투르케스탄)만 법적으로 구별된다: 잔여권을 연방이 대행하는 구성국([[연방_권한_분장]]).
- 상원 의석 배분과 개헌 산수: 러시아 36석, 개헌 동의 부결선(3분의 1 초과) 42석 — **러시아 혼자서는 헌장을 지키지도 고치지도 못한다.**
- 구성국 수반·수반 회의: [[연방_권한_분장]] §2.

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1918 말 | 연방 일괄 개편 고안 착수 — 명문화 직후, 강화 회의 개막 전 골격 완성이 목표([[연방_성립_협상_경위]]) |
| 1919 봄~늦가을 | 가입 협상 — 9개 구성국과 유보 부록 타결. 폴란드·한국·핀란드 세 건은 부총리가 직접([[연방_가입_의정서_일람]]·[[연방_성립_협상_경위]]) |
| 1919.11.20 | 의정서 일괄 조인 |
| 1919.12.6 | 헌장 공포 — 13칭호 겸위·구성국 명부 확정. 한국은 국호에서 '제국'을 빼고 왕국으로 편입, 급진파는 조인 거부 후 이산 |
| 1920.1.1 | 시행. 연방 기관 모스크바 이전, 첫 두마 모스크바 개원. 구성국 의회 첫 선거 — 첫 의결로 의정서 추인 |
| 1920 | 돈바스 경계 타결 — 우크라이나 귀속 + 광산 규정 연방 관할 (상원 표결이 실제 갈라진 드문 사례) |
| 1922 | 극동, 교육 유보권·공국 승격 요구 개시 (발단: 연해주 조선인 학교의 관할) |
| 1924 | 총독주 3곳 임명 참사회 → 선출 의회 전환 (헌장 부칙 제8항) |

〔편집 메타 OOC〕 결성 동력 3계기(명문화의 불가역화·강화 회의의 정당성 경쟁·전후 청구서 일괄 처리)는 [[연방_성립_협상_경위]] OOC에 정리. 설계 준거: 독일 제국 1871(이질적 구성국 + 법률 통칭 + 유보권 = 바이에른 모델) + 동군연합(13왕관 1머리). 왕관이 유일한 접착제인 것은 차르 실권 상실로 인적 충성 축이 빠진 자리의 답이며, 통치하지 않는 왕관이라 중립 상징이 될 수 있다는 논리. 탈퇴 조항 부재 = 최근 실패한 결합 형식들(동군연합·이중제국) 대신 연방을 고른 이유("다시는 못 나가게")가 제25조로 봉인된 구조. 한국 편입의 법리 = 보호조약 제1조를 파기하지 않고 조항이 가리키는 대상을 옮김(왕관은 차르에게 겸위) — 값은 두마 42석·유보 5종·구 조약과 차관의 일괄 청산·개발 투자("임금을 잃고 의회와 무부채를 얻는 거래"). 상원 배분(반당 62석·총 124석)은 협상 산물이라 깔끔한 수가 아닌 것이 정상. 인구는 기준계.
