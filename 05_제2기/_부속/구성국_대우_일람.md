# 구성국 대우 일람

> 대우의 근거 문서는 [[연방_가입_의정서_일람]], 유보 목록은 [[연방_구성국_일람]], 각국이 유보를 얻은 사정은 [[연방_성립_협상_경위]]. 여기엔 비교표만 둔다.
> 공식 등급제는 없다 — **유보 목록이 곧 대우다.**

## 자치의 실측 (유보 5축: 정부·부대·사법 종심·화폐·기타)

| 층 | 구성국 | 실측 |
|---|---|---|
| 최상 | **핀란드** | 화폐 완전 자주(마르카)·관세·우편·시민권 명부 — 유일하게 연방 전속을 셋 뚫음 |
| 상위 | **한국** · 폴란드 | 한국 = 정부·부대·교육·화폐(연동)·사법 5종 / 폴란드 = 4종(화폐 없음) |
| 중위 | 발트 · 우크라이나 | 사법(발트) · 농지·언어(우크라) 중심 |
| 하위 | 백러시아 · 캅카스 3국 | 교육·언어·관습법 수준 |
| 최하 | 총독주 3 | 유보 0 — 잔여권도 연방 대행([[연방_권한_분장]]) |

## 의전 서열 (대칭호 전례순 — [[국가헌장_조문]] 제3조)

러시아 → 우크라이나 → 폴란드 → 시베리아 → 조지아 → 투르케스탄 → **한국** → 핀란드 → 백러시아 → 발트 → 아르메니아 → 아제르바이잔 → 극동.

**의전과 실질은 다른 축이다** — 조지아는 의전 5위·실질 하위, 핀란드는 의전 8위·실질 최상. 시베리아는 의전 4위인 총독주다.

## 병역·화폐의 실측

| 축 | 실측 |
|---|---|
| **병역** | 징병(러시아·우크라·백러·발트) / 지원병(한국·캅카스 3국·투르케스탄) / **병역세**(핀란드) — [[연방군]] |
| **화폐** | 루블(11곳) / 유보 화폐 2 — 핀란드 마르카·한국 원(모두 루블 준비 담보 발행·고정 환율) — [[연방_재정과_화폐]] |
| **일상 침투** | 얇음(핀란드) → 중간(한국·폴란드·조지아·발트) → 깊음(우크라·백러·캅카스 동부) → 전부(총독주) — [[연방_권한_분장]] §침투 실측 |

## 연방 투자의 지리

| 축 | 대상 | 근거 |
|---|---|---|
| **동방 개발** | 극동 · 한국 (철도·항만·무역) | [[동방_개발_계획]] — 제8호 의정서 개발 조항 |
| 유전 배분 | 아제르바이잔 (정률, 1929 재협상) | 직할의 값([[연방_구성국_일람]]) |
| 분담금 | 전 구성국 (인구 비례 갹출) | [[연방_권한_분장]] |

## 한국의 위치 (종합)

| 축 | 실측 |
|---|---|
| 자치 | 상위 — 유보 5종, 핀란드 다음 급 |
| 연방 대표 | 두마 42석(3위) · 상원 8석 |
| 재정 | 구 차관 소각으로 무부채 출발(1920) · 관세는 표준 규칙(연방) · 세입은 직접세 중심 |
| 투자 | **동방 개발의 교두보** — 개발비 최대 배정지, 태평양 관문 |
| 인적 경로 | 자국 정부·의회 경로(과거 자격 유보) + 연방직(러시아어 문관시험)·고원([[연방_행정과_문관제]]) |
