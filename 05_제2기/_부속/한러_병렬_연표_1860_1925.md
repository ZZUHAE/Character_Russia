# 한·러 병렬 연표 (1860~1925)

> **★1904년 이전 = 공유 역사**(실제사 그대로 — [[_고증_바이블]]) / **1904~05 러일전쟁 = 분기점** / 이후 = 이 세계의 길.
> 1915~18의 상세는 소설 「북극성 아래」와 [[한국_편입_경과_1918_1920]], 1919~25의 상세는 [[정치_연대기_1919_1925]]가 담당 — 여기엔 굵은 뼈대만.

## 제1기 — 접촉과 개항 (1860~1894, 공유 역사)

| 연도 | 조선 | 러시아 |
|---|---|---|
| 1860 | | **베이징 조약 — 연해주 획득.** 조선과 두만강 국경 접촉 시작 |
| 1863~ | 함경 농민의 연해주 이주 시작([[러시아_제국_내_조선인_사회]]) | 이주민 수용 — 원호인·여호인의 기원 |
| 1863 | 고종 즉위(대원군 섭정) | 1861 농노 해방 직후의 개혁기 |
| 1876 | 강화도 조약 — 일본에 개항 | |
| 1881 | | 알렉산드르 2세 암살 — 반동기 |
| 1884 | 갑신정변 · **조러 수호통상조약**(수교) | |
| 1885~87 | 거문도 사건 — 영국이 러시아 견제로 점거 | 영러 그레이트 게임의 극동 파급 |
| 1891 | | **시베리아 횡단철도 착공** |
| 1894 | 동학농민운동 · 청일전쟁 · **갑오개혁 — 신분·과거의 법적 폐지**([[한국_사회_1925]]) | 니콜라이 2세 즉위 |

## 제2기 — 러시아의 부상 (1895~1903, 공유 역사)

| 연도 | 조선 | 러시아 |
|---|---|---|
| 1895 | 을미사변(일본의 왕후 시해) | **삼국간섭 주도** — 일본의 요동 반환 |
| 1896 | **아관파천 — 고종, 러시아 공사관으로**. 러 군사교관·재정고문 초빙 | 청러밀약 · 동청철도 부설권 |
| 1897 | **대한제국 선포**(칭제) · 고종 환궁 | 비테 금본위 개혁 |
| 1898 | **만민공동회 — 절영도 조차·한러은행·교관 철수 관철**(민심이 러시아를 밀어낸 기억 — [[_고증_바이블]] §ⓕ) | 뤼순·다롄 조차([[뤼순항]]) |
| 1900 | | 의화단 출병 — 만주 주둔 |
| 1903 | 용암포 사건 — 압록강 삼림 이권 마찰 | 극동 강경론 대두 · 영일동맹(1902)과 대치 |

## 제3기 — 분기와 보호국 (1904~1914)

| 연도 | 대한제국 | 러시아 |
|---|---|---|
| **1904** | 전장이 된 한반도 북부 — 부역·징발 | ★**러일전쟁 개전 — 분기점.** 뤼순 조기 사수([[러일전쟁_러시아_승리]]) |
| **1905** | **한러 보호조약** — 황실 존속(제1조)·외교 일부 제한·대일 공동방위. 자주파의 결성 기원 | **봉천 결전 승리 → 하얼빈 강화조약**(일본 극동 이권 상실·배상 9억 엔) · 1905 혁명 회피([[1905_혁명_회피]]) |
| 1906 | 재정 정리 차관 개시(한러은행 창구) | **산업동원 기본법** · 산업동원 협의회 설치([[제국_산업동원_협의회]]) |
| 1907 | **구 일본계 채권의 러시아 인수** — "이권보다 빚이 먼저 러시아인이 됐다"([[한국_편입_경과_1918_1920]]) | 영러협상 — 영국의 한반도 보호권 묵인(암묵 거래) |
| 1911 | | 청 신해혁명 — 중화민국(실제사대로) |
| 1914 | 부역·군수 동원의 부담 시작 | **1차대전 참전** — 협상국 |

## 제4기 — 격변 (1915~1919)

| 연도 | 대한제국 → 한국 | 러시아 |
|---|---|---|
| 1915 | **함경 지선 협약**(수비대·철도학당·원산 담보) · **밀지 파문 — 통문·상소·철시·유혈** · 협력 공사 소환 | 포탄 기근과 증산 — 내각의 전쟁 수행(소설 1부) |
| 1916 | 강압기 개막 — 경무 고문·**인천 담보**(차환 조건) | 금태환 정지 · 독일 대공세 방어 |
| 1917 | **무장 봉기와 진압 — "임금의 군대가 백성을 쐈다" · 부인 조서.** 충군 회로의 죽음 | 미국 참전(봄) · **전시 대위임**(가을 — 소설 2부) |
| 1918 | 협력 내각 복원 · 비공식 타진 | **종전(승전)** · 환수 전쟁과 **명문화**(소설 3부) · 연방 고안 착수 |
| 1919 | **구상 각서(1월) → 위임장 → 협상 → 체불 청산·부역 폐지 → 타결(10.21) → 연서 조인(11.20) → 어보 재가 — 조서 없음** | 9개 구성국 협상 · **국가헌장 공포(12.6)** |

## 제5기 — 연방 (1920~1925)

| 연도 | 한국 (왕국) | 연방 |
|---|---|---|
| 1920 | 시행 — 첫 국회 선거·**추인**·기관 전환·**소각식(연말)** | **연방 발족** — 첫 두마·모스크바 이전 |
| 1921 | 동방 개발의 교두보 지정 | 상원 첫 선출 · 개발 공채 |
| 1922 | | 극동, 유보권 요구 개시 — 발단은 **연해주 조선인 학교** |
| 1923 | **「한국은행법」**(합의 법안) | 분담금 파동 · 교회 자치법 무재가 발효 |
| 1924 | 둘째 총선 — **민족계 약진(~1/3)** · 한국은행 발권 인수 · 태평양 항로 | 첫 정당 선거 · **연방 루블** · 총대주교 복원 |
| 1925 | 국회 최대 쟁점 = **1929 유보 갱신 방침** | 금태환 논쟁 · 동등 지위 선언 상정 · **1929 시한 6종 대기** |

---

〔편집 메타 OOC〕 1904 이전 행은 전부 실제사(공유 역사) — 아관파천·만민공동회·용암포가 이 세계 한러 관계의 실제 뿌리라는 것이 이 연표의 요점이다(러시아는 조선을 구한 적도 밀려난 적도 있는 나라로 1904년을 맞는다). 갑오개혁 행은 [[한국_사회_1925]]의 신분 설계와 접속. 보호조약 연도는 1905(강화 직후). 1915~18의 회차 단위 상세는 소설 층(작중_타임라인)이 원장이며 이 표는 개관만 담는다. 격변 세대(1890~1900년생) 눈높이 연표(P1)는 이 표를 딛고 개인 체감 열을 더하는 다음 작업.
