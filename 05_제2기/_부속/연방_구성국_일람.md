# 연방 구성국 일람

> 해설·성립 경위는 [[제국의_국체와_연방_구조]]. 여기엔 자료만 둔다.

## 구성 원리

단위를 가르는 기준은 **역사적 정치체와 행정 전통**이지 민족이 아니다. 그래서 러시아인 정착지인 시베리아와 극동이 각각 구성국이고, 세 민족이 사는 발트가 하나이며, 여러 언어가 쓰이는 투르케스탄도 하나다. 민족 분포와 구성국 경계는 어디서도 정확히 겹치지 않는다.

## 유보권 (구성국이 연방에서 떼어 간 권한)

균일하지 않다. 각자가 협상 테이블에 들고 온 것이 달랐다.

| 구성국 | 유보 사항 |
|---|---|
| **핀란드** | 자체 화폐(마르카)·관세·우편, 평시 자체 부대, 교육·종교, **자체 시민권 명부** |
| **폴란드** | 교육·종교(가톨릭), 자체 사법, 평시 자체 부대, 산업 규제 |
| **한국** | 황제 칭호, 자체 정부·의회, 평시 자체 부대, 교육·과거 자격, 자체 화폐 발행(루블 연동) |
| **발트** | 자체 사법(발트법), 교육(독일어·현지어), 항만 자치 |
| **우크라이나** | 교육·언어, 농지 제도, 곡물 검사 |
| **조지아·아르메니아·아제르바이잔** | 교육·종교, 관습법 사법 |
| **백러시아** | 교육·언어 |
| **시베리아·극동·투르케스탄** | 없음 (총독주 — 요구할 힘이 없었다) |

## 연방 직할 (연방이 구성국에서 떼어 간 영역)

| 구역 | 소재 | 사유 |
|---|---|---|
| **바쿠 유전** | 아제르바이잔 | 제국 석유. 유전 수입 정률을 아제르바이잔에 배분, **10년마다 재협상(다음 1929)**. ❓경계 미확정 |
| **주요 군항** | 극동(블라디보스토크)·발트(리가·레발)·러시아(크론시타트) | 연방군 기지 |
| **연방 수도 구역** | 페테르부르크 일부 | 청사·의사당 일대 |

## 경계 분쟁

| 지점 | 다투는 곳 | 상태 |
|---|---|---|
| **연해주 조선인 관할** | 극동 ↔ 한국 | ❓미해결. 양쪽 명부 동시 등재 수만 명 |
| **바쿠 직할 경계** | 연방 ↔ 아제르바이잔 | ❓미해결. 시가지·급수·철도 범위 |
| 돈바스 | 우크라이나 ↔ 러시아 | 1920 타결 — 우크라이나 귀속 + 광산 규정은 연방 |
| 리투아니아 | 폴란드 ↔ 발트 | 1920 타결 — 폴란드 귀속 |
