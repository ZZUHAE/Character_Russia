# 한국 편입 경과 (1918~1920)

> 결과 상태는 [[한국_왕국]], 의정서 등록은 [[연방_가입_의정서_일람]] 제8호. 여기엔 경과의 문서만 둔다.

## 편입의 법적 성격

열세 구성국 가운데 **한국의 편입만 조약 행위**다. 다른 열두 곳은 제국 내부 영토의 재편이지만, 한국은 자기 조약([[한러_보호조약]])을 가진 보호국이었으므로 편입은 그 조약 체계를 처리하는 국제 문서를 요했다. 제8호 의정서가 아홉 통 중 가장 두꺼운 이유다.

처리의 방식은 승계가 아니라 **청산**이었다 — 보호국 시대의 서류철을 이어받는 대신 통째로 닫았다.

## 경과표

| 단계 | 시점 | 사실 |
|---|---|---|
| 출발 상태 | 1918 말 | 협력 내각 복원·공사관 체제. 어전은 침묵 |
| 협상 개시 | 1919 봄 | 전 구성 예정지 동시 개장 — 한국 상대는 정부 전권단 |
| 타결 | 1919.10.21 | 제8호 의정서 — 국호에서 '제국' 제외·왕국 편입·유보 5종 + **청산·개발 3조**(아래) |
| 조인 | 1919.11.20 | 9통 일괄 조인(페테르부르크). 급진파 조인 거부 선언 후 이산 |
| **재가** | 1919.11 말 | **고종의 재가 — 마지막 국사 행위.** 자기 왕관을 옮기는 문서에 어보가 찍혔고, 이후 그는 전왕이다 |
| 열강 통고 | 1919.12 | 편입을 각국에 통고. 한성 외국 영사관의 인가장은 연방 외무부 명의로 갱신 |
| 공포·시행 | 1919.12.6 → 1920.1.1 | 헌장 공포 — 황실 폐지·차르 겸위. 반대는 상소·지면·철시로 표출 후 잦아듦 |
| 기관 전환 | 1920 | 아래 전환표 |

## 청산·개발 3조 (제8호 의정서 특별 조항)

| 조 | 내용 |
|---|---|
| **1. 구 조약·이권의 일괄 실효** | 한러 보호조약과 부속 협약(함경 협약 등)·보호국기 이권 계약(삼림·광산 등) — **편입과 동시에 실효.** 철도는 연방 전속으로 흡수 |
| **2. 구 차관의 연방 인수·소각** | 보호국기 차관 잔액(~3,000만 원)의 채권은 연방이 승계 후 **소각** — 원산 해관세 담보 자동 소멸. 한국 재정은 이자 부담 없이 출발 |
| **3. 연방 개발 투자** | 철도 연결·항만 확장에 대한 연방 투자 약속 — [[동방_개발_계획]](1921)의 조약상 근거 |

관세 특례는 없다 — 한국은 표준 구성국 규칙(관세 = 연방)을 받았고, 세입 구조는 직접세 중심으로 재편됐다.

## 기관 전환표 (1920)

| 구 기관·제도 | 전환 |
|---|---|
| 러시아 공사관 | 폐지 — 세관·항만청·연방 철도국 등 연방 기능 기관으로 분속 |
| 외부(外部) | 폐지 — 외교권 연방 전속 이관, 재외 한국인은 연방 영사 관할 |
| 궁내부 | 해체 — 전왕 예우 사무소로 축소 |
| 러시아 주둔군(원산·마산포) | 연방군 **군항 직할**로 지위 전환 |
| 함경 수비대 | 제7조 4년 시한 만료(1919)로 소멸 — 연장 없음 |
| 치안군 | "평시 자체 부대" 유보로 승계 |
| 13도 지방 체계 | 유지 |

〔편집 메타 OOC〕 채무 인수·소각의 준거 = 해밀턴의 주 채무 인수(1790) — 연방이 구성원의 옛 빚을 삼키는 것은 연방 결속의 고전 문법. 청산 방식(승계 아닌 단절)은 동등 대우 원칙의 귀결: 보호국 회계(환부율·특례 흥정)를 연방 안으로 끌고 오지 않는다. 함경 수비대 소멸은 1기 canon의 4년 자동 종료 시한(1915 조인+4)이 편입 일정과 맞물린 산술. 고종 재가는 법적 완결 장치이자 "조용히 사슬을 택한 임금" canon의 종점 — 소설 3부(1918)와는 시간이 겹치지 않는다.
