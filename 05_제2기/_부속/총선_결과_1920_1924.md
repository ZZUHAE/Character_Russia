# 총선 결과 (1920 · 1924)

> 제도는 [[두마_선거법_1919]], 원내 지형 해설은 [[정당_체계]]. 여기엔 표만 둔다.
> 두 표의 열이 다르다 — 1920년에는 셀 정당이 없었다.

## 제1차 총선 (1920)

도별 순차 투표 3주(부칙 상한). 정당 명부 없음 — 당선인 성분별 집계.

| 성분 | 의석 | 기반 |
|---|---|---|
| 젬스트보·지주 명망가 | ~165 | 농촌 선거구 — 부과 대장의 이름들 |
| 관료·법조·전문직 | ~120 | 도청 소재지·수도권 |
| 상공인 | ~85 | 도시 별도 선거구·협의회 계열 |
| 농촌 조합·협동조합 명사 | ~85 | 흑토·시베리아 농촌 |
| 교회 관련 평신도 명사 | ~25 | (성직자 겸직 금지 조항의 우회) |
| 노동자 대표 | ~15 | 공업 도시 |
| 기타·무소속 성격 불명 | ~29 | |
| **계** | **524** | |
| 투표율 | **~57%** | 첫 선거·명부 갈음(1919 대장)의 한계 |

개원 후 원내 클럽 결집 → 1921~22년 정당 창당으로 이어짐([[정당_체계]] 연혁).

## 제2차 총선 (1924) — 첫 정당 선거

| 정당·회파 | 의석 |
|---|---|
| **진보당** | ~255 |
| 농민동맹 | ~90 |
| 국민동맹 | ~45 |
| 폴란드 콜로 | ~30 |
| 무슬림 회파 | ~25 |
| 한국 협력계 (진보당 제휴) | ~22 |
| 한국 민족계 회파 | ~20 |
| 노동파 | ~14 |
| 핀란드 의원단 | ~11 |
| 기타 회파·무소속 | ~12 |
| **계** | **524** |
| 투표율 | **~63%** | 새 명부 완비·정당 동원 |

- 같은 해 구성국 의회 선거: 러시아 — 농민동맹·국민동맹 연합 다수([[러시아_구성국]]) / 한국 — 협력계 다수·민족계 약 3분의 1([[한국_왕국]]) / 총독주 3곳 첫 선출 의회.

〔편집 메타 OOC〕 의석·투표율은 기준계 — 유지할 구조는 ①1920 = 성분 집계·1924 = 정당 집계라는 열의 차이 ②진보당 단독 과반(263) 미달 + 한국 협력계 제휴로 과반 ③투표율 검산 준거 = 원역사 1917 제헌의회 64%(선거법 노트 OOC). 도별 세부·선거구 일람은 필요해질 때 별도 부속으로.
