# 정치 연대기 (1919~1925)

> 각 제도 노트의 연혁을 한 장으로 모은 색인. 상세는 각 링크.

| 연도 | 사실 |
|---|---|
| **1918 말** | 명문화 협상·서명(일자 ❓ 소설 3부) · 연방 일괄 개편 고안 착수 |
| **1919 봄~가을** | 가입 협상 — 9개 구성국과 유보 부록 타결([[연방_가입_의정서_일람]]) |
| 1919.10.21 | 한국 제8호 의정서 타결 — 급진파 조인 거부·이산([[한국_왕국]]) |
| 1919.11.20 | **의정서 9통 일괄 조인** (페테르부르크) |
| 1919.11.27 | 구 두마, 헌장 채택 (3분의 2) |
| **1919.12.6** | **국가헌장·조직법 묶음 공포** — 선거법·러시아 조직법 포함([[국가헌장_1919]]) |
| **1920.1.1** | **헌장 시행** — 연방 발족 |
| 1920 | 연방 기관 모스크바 이전 · **첫 선거의 해**(두마 524·구성국 의회 — [[총선_결과_1920_1924]]) · 구성국 의회 첫 의결 = 의정서 추인 · 첫 내각 신임([[연방_내각]]) · 두마 조직법·내각법·경찰 개편법(정치경찰 폐지)·출판법·결사법 제정 · 대심원 개원(모스크바) · 돈바스 경계 타결 |
| **1921** | 국가평의회법 — **상원 첫 선출**(124석, 추첨 배반 — [[국가평의회]]) · 첫 수반 회의 · 신분 특권 정리법 · 재판 공통 최저 기준법 · 전시 조달 조사 완결 · 동방 개발 발족 — 첫 개발 공채 발행([[연방_재정과_화폐]]) |
| **1922** | 극동, 교육 유보권·공국 승격 요구 개시([[제국의_국체와_연방_구조]]) · 재정 균형 회복 — 감군 완료(상비 ~90만, [[연방군]]) |
| **1923** | 분담금 사정 파동 — 3국 납부 유예, 상원 조정 타결([[연방_권한_분장]]) · 선거구 조기 재획정 법안 — 상원 첫 재의 요구, 두마 재의결 정족 미달 폐기 · **「교회 자치법」 최초의 무재가 발효**([[왕관과_궁정]]) |
| **1924** | **둘째 선거의 해** — 두마 제2차 총선(첫 정당 선거, [[정당_체계]]) · 총독주 선출 의회 개원 · 러시아 의회 선거 — 농민동맹·국민동맹 연합 정부([[러시아_구성국]]) · 총선 후 내각 총사퇴·재신임 첫 적용 · 정교회 공의회 — 총대주교 선출 · **화폐 개혁 — 금 준비 신루블**([[연방_재정과_화폐]]) |
| **1925** | 상원 첫 정기 개선(한 반 62석) · 수반 회의에 "동등 지위 선언" 채택안 상정 · 러시아 의회 토지 법안 계류 · **금태환 재개 논쟁**(영국 복귀 여파 — [[연방_재정과_화폐]]) · **헌장 개정 0회 유지** |

## 앞에 놓인 시한 (1925년 현재)

| 연도 | 예정 |
|---|---|
| 1928 | 셋째 선거의 해 (두마·구성국 의회) |
| **1929** | **유보권 조약 일괄 갱신 · 황실비 정액 만료 · 선거구 재검토 · 분담금 사정 · 바쿠 배분 재협상** |

〔편집 메타 OOC〕 이 표는 각 제도 노트 연혁의 종합 색인이며 새 사실을 만들지 않는다 — 어긋나면 개별 노트가 우선. 1929년 시한 집중은 1919년 협상이 10년·5년 주기를 같은 기점에서 시작한 산술적 귀결.
