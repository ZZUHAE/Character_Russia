# 지방행정과 치안

## 1. 개요

지방은 구성국의 것이다(헌장 제2조 잔여권). 연방의 행정이 땅 위에 보이는 곳은 **세관·연방 철도역·우편국**뿐이고, 치안의 손은 국경에서 끝난다. 정치경찰은 1920년에 폐지됐고 승계 기관이 없다.

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **지방제(러시아)** | 도(губерния) — 도지사는 **러시아 정부가 임명**. 도 아래 군(уезд). 자치는 젬스트보(도·군)와 시두마 — 도로·학교·보건·통계, 재원은 부과금(직접세 계열) |
| **지방제(타 구성국)** | 각국 자체 — 한국 13도([[한국_왕국]]), 핀란드 주(州) 등. 연방 관여 없음 |
| **총독주** | 총독부 행정 — 내무부 계통([[연방_내각]]). 1924년부터 선출 의회가 입법·예산 의결 |
| **경찰** | **구성국 소관** — 도시 경무·농촌 순찰·형사. 연방 차원 경찰 없음 |
| **연방의 손** | 국경 경비(군무부)·세관 감시(재무부)·연방 철도 경비(교통부) |
| **정치경찰** | 1920년 폐지 — 승계 기관 없음. 방첩(대외 정보·간첩 수사)은 **군무부 소관** |

## 3. 구성·조직

| 층 | 기관 | 임면 |
|---|---|---|
| 구성국 | 도지사·주지사 | 구성국 정부 |
| 자치 | 젬스트보 의회·시두마 | 주민 선거(구성국 법) |
| 총독주 | 총독부·군수 | 연방(내무부 계통) |
| 연방 | 세관·철도 경비·국경 경비 | 소관 부처 |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1920 | 「경찰 개편법」 — 정치경찰(오흐라나)·헌병단 폐지. 형사·치안 기능은 구성국 경찰로, 방첩은 군무부로, 철도 헌병은 교통부 경비로 분속. 총독주 외 총독직 일괄 폐지 — 도지사 체계로 |
| 1921 | 젬스트보 부과금이 구성국 직접세 체계에 편입([[연방_권한_분장]]) — 유권자 명부의 물적 기반 |
| 1924 | 총독주 선출 의회 개원 — 총독부 예산이 처음으로 의회 의결을 거침 |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| 총독주 경찰의 이관 (내무부 계통 → 장래 자치 정부) | 총독주 의회 ↔ 내무부 | 승격 문제와 연동 — 1929 |
| 구성국 간 수배 공조 (연방 경찰 부재의 실무 공백) | 구성국 경찰들 | 수반 회의 실무 협정으로 운영 — 법제화 논의 |

---

〔편집 메타 OOC〕 오흐라나 폐지의 법리 = 차르 직속 기관(1기 canon)의 존재 근거가 열거주의(제22조)로 소멸 — 원역사 1917년 2월 폐지의 본작 판은 혁명이 아니라 개편법 한 줄. 승계 기관을 두지 않은 것은 설계 결정(연방 경찰의 부재가 "얇은 연방"의 치안판). 젬스트보 강화는 직접세=구성국 세원 구조의 귀결. 1기 canon 오흐라나·지방총독제 노트는 동결 유지 — 이 노트가 1925년의 상태를 서술한다.
