# 사법 제도

## 1. 개요

**재판은 구성국의 일이고, 연방은 최고심 하나만 가진다.** 연방에 하급 법원이 없다 — 연방법이 걸린 사건도 1심·2심은 구성국 법원이 재판하고, 연방 사항의 상고만 **연방 대심원**(모스크바)으로 올라간다. 법률의 위헌 여부를 재판하는 제도는 없다.

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **법원 구조** | 구성국 법원(1·2심 — 치안·지방·항소) + **연방 대심원**(최고심). 연방 하급 법원 없음 |
| **상고 경로** | 연방 사항(연방법·전속 사항·구성국 간 상사) = 대심원 상고. 구성국 사항 = **사법 유보국**(한국·폴란드·발트·조지아·아르메니아·아제르바이잔)은 자국 법원 종심, 그 외는 대심원 상고 가능([[연방_권한_분장]]) |
| **대심원** | 민사부·형사부·행정부(行政部). 판사는 법무부 제청·총리 부서로 임명, **종신 신분 보장** |
| **위헌 심사** | 없음 — 법원은 법률의 효력을 심사하지 않는다. 연방-구성국 권한 다툼은 상원 조정([[국가평의회]]) |
| **검찰** | 대심원 검사국(연방 사항) + 구성국 검찰(각국 법제) |
| **배심** | 형사 중죄 배심 — 구성국별 시행(1864년 개혁 유산의 승계) |
| **재판 원칙** | 공개 재판·구두 변론·판사 신분 보장 — 전 구성국 공통 최저 기준(연방 법률) |

## 3. 구성·조직

| 기관 | 소재 | 비고 |
|---|---|---|
| 연방 대심원 | 모스크바 | 1920 개원. 3부 구성 |
| 대심원 검사국 | 모스크바 | 법무부 소관([[연방_내각]]) |
| 구성국 법원 | 각국 | 사법 유보국은 자국 법제(발트법·한국 사법 등) — 그 외는 1864년 체계의 승계 |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1919 | 헌장 — 사법 관련 전속·유보의 배분을 조약과 법률에 위임(제5조) |
| 1920 | 「연방 대심원법」 — 대심원 개원(모스크바), 구 최고 사법 기관의 계속 사건 승계 |
| 1921 | 재판 공통 최저 기준법 — 공개·구두·판사 신분 보장을 전 구성국에 |
| 1924 | 상고 사건 적체 시작 — 상사 사건의 대심원 집중 |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| 상고 적체 — 부(部) 증설 또는 상고 제한 | 대심원 ↔ 법무부 | 법 개정 논의 |
| 재판 관할 선택(계약서의 관할 조항으로 구성국 고르기) 규제 | 상공계 ↔ 법무부 | 방치 — 규제 조문 없음 |

〔편집 메타 OOC〕 구조 준거 = 독일 제국(제국법원 Reichsgericht 하나, 재판은 각국 법원 — 연방 하급심 없는 얇은 사법 연방) — 미국식 연방 지방법원 체계는 채택하지 않음(연방이 얇다는 설계와 상충). 위헌 심사 부재 = 1925년 시대 표준(헌법재판은 오스트리아 1920이 최초 발명 — 본작 미채택, 권한 다툼은 정치적 해결). 1864년 사법개혁(공개·배심·신분 보장)은 1기 canon의 유산으로 구성국 법원에 승계. 배심·법원 등급 세부는 구성국 소관이라 의도적으로 얕게 둠.
