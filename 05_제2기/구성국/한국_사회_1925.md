# 한국의 사회 (1925) — 신분·학교·말·살림

## 1. 개요

1925년 한국에서 신분은 **법에도 대장에도 없고, 혼인과 호칭과 제사에 남아 있다.** 법적 폐지는 오래전 일이고(갑오년), 실제 재편은 편입이 했다 — 법령이 아니라 **선거 명부와 세금 고지서와 학교 사다리**가 사람의 자리를 다시 정했다.

## 2. 신분의 처리

| 항목 | 내용 |
|---|---|
| **법적 지위** | 신분·반상 차별은 **갑오년(1894) 법령으로 이미 폐지** — 과거제·노비제도 그때 끝났다. 이후 어떤 법도 신분을 되살린 적 없다 |
| **연방 법과의 관계** | 연방의 신분 특권 정리법(1921 — [[사회_기본_법제]])은 한국에 적용될 것이 없었다 — 조선의 신분은 제국 신분 대장에 등재된 적이 없다. **종이 위에서는 한국이 27년 먼저 신분을 지운 셈이다** |
| **★사실상의 재편 ①선거** | 선거 자격 = 직접세 납부 가구의 성년([[두마_선거법_1919]]) — **족보가 아니라 납세가 정치 자격.** 몰락 양반은 명부에 없고 개항장 객주는 있다 |
| **★사실상의 재편 ②세금** | 지세 정리(1920~) — 면세 관행의 종말. **족보가 세금을 막지 못하게 된 것**이 반상 구별의 실질적 마지막 기둥을 치웠다 |
| **★사실상의 재편 ③임용** | "과거 자격" 유보([[연방_가입_의정서_일람]] 제8호) — 한국 관리 임용은 자국 자격 제도로. 구 급제·음서 이력의 경과 인정을 거쳐 **신학문 시험 임용으로 전환 중** |
| **1925 실태** | 양반 = 계급에서 **가문 문화**로(혼처·호칭·좌차·제사에 존속). 중인 실무층 = 최대 수혜(신학문 관료·통역·기술의 모태). 천민 차별 = 법 밖 **관습으로 잔존** — 백정·무격에 대한 혼인·동석 기피는 어느 법령도 다루지 않았다 |

## 3. 학교와 말

**학교의 사다리**:

| 단 | 내용 |
|---|---|
| 서당 | 여전히 최다 — 농촌의 문자 입문. 취학의 절반 이상이 아직 여기서 시작 |
| 보통학교(관립·공립) | 1920년대 확장 중([[한국_왕국]]) — 수업은 조선어. 러시아어는 상급 선택 과목 |
| 고등보통·전문 | 한성·평양·대구 — 법률·의학·상업·사범 |
| **철도학당** | 1915년 협약 제11조가 시작(연 20명) → 편입 후 확대. 기관사·기술자의 문 — **이 세대의 가장 확실한 사다리** |
| 유학 | 페테르부르크·모스크바(연방 경로) / 상해·동경(사비 — 소수) |
| 여학교 | 한성·개항장에 소수 — 전신국·학교·상점이 받아 주는 좁은 문 |

**말의 세 층**:

| 층 | 쓰임 |
|---|---|
| 조선어 | 일상·행정·학교·국회 — **교육 유보의 실물.** 관보도 법률도 조선어다 |
| 러시아어 | 연방 기관·철도·문관시험([[연방_행정과_문관제]]) — **가르치지 않되, 없으면 오르지 못하는 사다리.** 강제가 아님은 협력계의 자랑이고, 출세에 필수임은 민족계의 논거다 |
| 한문 | 구세대의 교양 — 제사·족보·상소의 말. 젊은 층에서 빠르게 좁아짐 |

세대 단층이 말에서 제일 선명하다 — **조부는 한문으로 쓰고, 아버지는 조선어 공문을 쓰고, 아들은 러시아어 야학에 다닌다.** 개항장과 철도역의 간판은 조선어·러시아어 병기.

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1894 | 갑오 법령 — 과거·노비·반상 차별의 법적 폐지 |
| 1915 | 철도학당 개설(협약 제11조, 견습 연 20명) |
| 1920 | 교육·과거 자격 유보 발효 — 학제는 한국의 것으로. 지세 정리 개시 |
| 1922~ | 보통학교 확장기 — 개발 세입과 무부채 재정의 배당 |
| 1924 | 철도학당 확대 개편(동방 개발 인력 수요 — [[동방_개발_계획]]) |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| 의무교육 도입 — 재원이 걸림 | 국회 문교 논쟁 | 계류 |
| 러시아어 교과 확대 — 실용론(협력계 일부) ↔ "사다리를 의무로 바꾸지 말라"(민족계) | 국회 | 연례 논쟁 |
| 천민 차별 관습 — 지면의 문제 제기 수준, 입법 움직임 없음 | 신문 논설 ↔ 침묵 | 잠복 |

〔편집 메타 OOC〕 갑오개혁(1894)은 POD(1904~05) 이전의 공유 역사라 그대로 차용 — 법적 폐지 선행 + 관습 존속이라는 구도 자체가 실제사다. "27년 먼저"는 러시아 신분 대장 폐지(1921)와의 대조에서 나오는 이 세계의 사실. 편입의 사실상 재편 3종은 신분을 정면으로 건드린 법이 하나도 없는데 신분 질서가 재편되는 구조 — 명부·고지서·사다리가 법령보다 힘이 셌다는 설계. 학제·언어의 가드레일: 수업어 = 조선어가 기본이라는 것이 일본식 교육령과의 차별선(교육 유보의 존재 이유)이며, 러시아어는 강제 없는 출세어라는 미묘함으로만 존재. 물가·임금은 1920년대 실제 경성 감각을 원(圓) 단위로 옮긴 기준계 — 못박는 사실 아님. 1890~1900년생 세대 서사(P1 눈높이 연표·P2 인생 트랙)의 토대 문서.
