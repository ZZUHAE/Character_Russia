# 한국의 연방 풍경 (1925) — 시설·도시·산업

## 1. 개요 — 연방은 문과 선과 돈으로 보인다

1925년 한국에서 연방의 행정 건물은 없다 — 공사관은 폐지됐고 총독부는 처음부터 없었다([[한국_왕국]]). 연방이 보이는 곳은 셋뿐이다: **문**(세관), **선**(철도·우편전신), **돈**(은행). 학교·법원·경찰서·관청의 간판은 전부 한국의 것이다.

그래서 이 나라에서 연방의 존재감은 **지리로 나타난다** — 어느 도시에 문과 선과 돈이 모여 있는가가, 곧 연방이 어디에 있는가다.

## 2. 연방 기관 일람 (한국 소재)

| 기관 | 소재 | 실물 |
|---|---|---|
| 연방 세관 | 인천·원산·부산·청진·마산 | 항구의 문 — 연방기가 걸린 몇 안 되는 건물 |
| 연방 철도국 한국 관리부 | **한성역 병설 청사** | 종관·함경·경의 각선의 운영 본부 |
| 연방 체신(우편·전신) | 중앙우편국(한성)·각 도시 우편국 | 우표는 연방 우표 — 일상에서 가장 자주 만지는 연방 |
| 연방 국립은행 한성 지부 | 한성(구 한러은행 본점 건물) | 국고 대리·개발 공채 창구([[연방_재정과_화폐]]) |
| 군항 사령부 | **원산·마산포**(직할 구역) | 연방군이 보이는 유일한 곳 — 도시 쪽에선 담장과 초소만([[연방군]]) |
| 없는 것 | — | 연방 법원(사법 유보)·연방 경찰(원칙상 부재)·연방 행정청 |

## 3. 철도의 풍경 — 선이 만든 세계

| 항목            | 내용                                                                                                                       |
| ------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **광궤 종관**     | 1905년 인수한 철도를 광궤로 개축(1906~10년대) — 시베리아·만주와 궤간이 같다. **"레일의 폭이 소속을 말한다"**                                                  |
| **부산발 모스크바행** | 1925년의 상징 — 환적 없는 직통 열차, 편도 열이틀. 의원·유학생·상인이 같은 찻간에 탄다                                                                    |
| **한성역**       | 1924년 신축 준공 — 돔을 얹은 붉은 벽돌, **한성에서 가장 큰 연방 건물은 관청이 아니라 역이다**                                                              |
| 관사촌           | 연선 주요역의 철도 사택 단지 — 기관고·철도 병원·구매조합. 철도원 제복은 한국에서 가장 흔한 연방 제복                                                              |
| ★연선 철도 학교     | 철도국이 직원 자녀를 위해 부속 학교를 운영(수업에 러시아어 비중) — **한국 학제(교육 유보) 밖의 학교가 한국 땅 위에** 있는 셈. 극동 조선인 학교 문제의 한국판 거울([[제국의_국체와_연방_구조]] §5) |
| 역명판           | 조선어·러시아어 병기 — 개항장 간판과 함께 이중 문자의 풍경                                                                                       |

## 4. 도시의 지도 — 개발이 북동쪽으로 기울었다

연방의 개발축(시베리아~극동~한반도, [[동방_개발_계획]])은 **북·동**을 향한다 — 도시의 운명이 그 축을 따라 갈렸다.

| 도시 | 1925년의 모습 |
|---|---|
| **한성 (~35만)** | 수도 — 국회·한국은행 본점·한성역·중앙우편국. 정치와 돈과 선이 모이는 곳 |
| **원산 (~9만, 급성장)** | ★**연방 제1항** — 군항(직할)과 상항(확장 공사)이 담 하나로 나뉜 도시. 태평양 항로 기점(1924)·해관·철도 기관구·러시아인 거류지와 정교회당. 함경 담보의 그 세관이 이제 개발의 문이 됐다 |
| **청진 (~5만, 신흥)** | ★**북방의 공업항** — 무산 철광을 업은 제철소(연방·한국 합작), 연해주 최단 항구. 십 년 전 어촌이었던 곳 — **연방 치하에서 태어난 도시**라 불린다 |
| **함흥 (~6만)** | **철도가 키운 도시** — 함경선의 결절, 관사촌·기관고·철도 학당 분교. 하얼빈의 소형판 같은 정거장 신시가와 구읍성이 한 도시에 두 겹 |
| **인천 (~7만)** | 한성의 관문 — 세관(1917년 담보의 기억)·서해 무역(대청). 꾸준하되 화려하지 않음 |
| **부산 (~8만, 정체)** | ★**가장 컸을 도시가 가장 조용한 항구** — 대일 무역의 관문이었으나 교역 축이 북으로 돌며 성장이 멎었다. 일본 영사관과 왜관의 기억. 모스크바행 직통의 시발역이라는 새 이름이 유일한 활기 |
| **마산포** | 군항 직할 — 해군 석탄기지. 도시라기보다 기지와 그 그림자 |
| 평양 (~11만) | 서북의 중심 — 광업(재허가 합작)과 곡물 집산. 개발축에서 반 발 비껴남 |

**행정구는 13도 그대로**([[한국_왕국]]) — 연방 직할은 군항 두 곳의 담장 안뿐이고, 철도 용지는 연방 재산이되 행정은 도(道)의 것이다. 새 지리는 행정이 아니라 **투자**가 그렸다.

## 5. 돈과 산업

| 항목 | 내용 |
|---|---|
| 화폐의 공존 | 시장은 원(한국은행권, 1924~), 역·세관·공채는 루블 — **생활은 원으로, 이동은 루블로** |
| 은행 지형 | 한국은행(발권·국고) / 연방 국립은행 지부(개발 공채) / 상업은행들 — 구 한러은행 후신과 객주 자본 은행이 경쟁 |
| 이권의 재편 | 구 러시아 이권(삼림·광산)은 편입 때 일괄 실효([[한국_편입_경과_1918_1920]]) → **허가권이 한국 정부로** → 재허가는 합작 형태(한국 자본 + 연방 자본). "산은 돌아왔는데 캘 돈이 모자라다" |
| 공업의 맹아 | 청진 제철·원산 조선(造船) 수리·정미·방직 — 개발 수요가 끌어올린 첫 세대 공장 |
| 수산 | 동해 어업 — 극동과 어장이 겹치는 바다. 극동의 어업권 요구([[연방_권한_분장]] §5)가 남의 일이 아님 |
| 군항 경제 | 원산·마산의 납품·수리·부식 조달 — 군항 담장 바깥을 먹여 살리는 조용한 수요 |

## 6. 의회의 풍경

| 항목 | 내용 |
|---|---|
| 국회 | 한성 — 구 관아를 개수한 의사당, 단원제 150석([[한국_왕국]]) |
| 두마 선거 | 4년마다 "선거의 해" — 42개 선거구, 투표소는 보통학교 교사(校舍). 이 땅에서 가장 새로운 풍경 |
| **의원의 기차** | 회기가 열리는 10월, 두마 의원들이 한성역에서 모스크바행에 오른다 — **편도 열이틀의 대표 여행.** 상원 의원 8인도 같은 열차다 |
| 전신 정치 | 모스크바의 표결이 다음 날 아침 한성 신문에 — 두 수도 회선의 끝이 이 나라 정치의 아침을 정한다 |

## 7. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| **연선 철도 학교의 관할** — 한국 학제 밖 학교의 존재 | 한국 문교 ↔ 연방 철도국 | 잠복 — 1929 갱신의 잠재 의제 |
| 개발의 남북 격차 — "예산이 북쪽으로만 간다"(호남·경상 의원) | 국회 예산 논쟁 | 연례 |
| 원산 상항·군항 경계(용지·급수) | 한국 정부 ↔ 군항 사령부 | 바쿠·모스크바 구역과 같은 유형 |
| 부산의 진정 — 대일 통상 재개 요구와 겹침 | 부산 상공계 ↔ [[연방_외교]] 현안 | 계류 |

| 철도 총연장(한국 내) | ~2,500km — 함경선 연장·종관 복선화 공사 중(1927 목표) |

| 도시 인구 | 한성 35만 · 평양 11만 · 원산 9만 · 부산 8만 · 인천 7만 · 함흥 6만 · 청진 5만 |

〔편집 메타 OOC〕 준거 = 동청철도·하얼빈 모델(철도 회사가 학교·병원·관사촌·도시 계획까지 운영한 실제 — 연방 철도국 존재감·함흥 "정거장 신시가"·연선 학교 장치의 원형. 단 치외법권·철도 경찰은 이식하지 않음 — 국내이므로 행정은 13도, 이것이 CER과의 차별선) + 궤간의 실제사(조선 철도는 표준궤로 부설됐고 러시아 광궤와 달랐다 — 본작은 1905 인수 후 시베리아 직결을 위해 광궤 개축했다는 설계로, "궤간 = 세력권"이라는 시대의 실제 문법을 따름) + 경성역 1925 준공의 라임(신역사 1924 준공으로 차용). 도시 설계의 축 = 실제사 반전: 일제하 한반도의 개발축은 남(부산~경성)이었으나 본작은 북·동(원산·청진·함흥) — 부산 정체·원산 제1항이 그 거울상이고, 청진은 실제사에서도 일제가 키운 신흥항이라는 점에서 "누가 키웠는가만 다른 도시". 연선 철도 학교는 극동 조선인 학교 쟁점의 국내 거울로 심은 1929 재료. 인구·연장·일수는 기준계.
