# 한국 (왕국)

## 1. 개요

한국은 연방 열세 구성국의 하나로, 지위는 **왕국**, 왕은 **차르**다([[국가헌장_조문]] 제3조 七). 왕은 페테르부르크에 있고 한국 땅을 밟은 일이 없으며, 그의 이름은 재가 문서와 교서 위에만 존재한다. **왕관의 현지 손은 따로 없다 — 국회의 신임으로 서는 한국 내각이 곧 그 손이다.**

국회는 협력계 다수, 민족계 야당의 양대 구도다. 덕수궁에는 **전왕(前王)이 침묵한 채 살아 있다.**

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **지위** | 왕국. 가입·유보는 제8호 의정서([[연방_가입_의정서_일람]]) |
| **왕** | 차르가 "한국의 왕(韓國王)" 칭호로 겸위. 왕의 국사 행위는 **한국 총리대신의 부서(副署)**를 요한다. 현지 대행자(총독·판무관류)는 두지 않는다 |
| **국회** | 단원제 150석. 선거 자격은 연방 선거법과 동일 — 직접세 납부 가구의 성년 전원([[두마_선거법_1919]]) |
| **정부** | **총리대신은 국회의 신임으로 정한다.** 내각은 국회에 책임 |
| **재가** | 법률은 국회 의결 + 왕의 재가. **기일 내 재가가 없으면 효력 발생**(헌장 제9조 미러) |
| **유보권** | 자체 정부·의회 / 평시 자체 부대 / 교육·과거 자격 / 자체 화폐 발행(루블 연동) / 자체 사법(자국 법원 종심) |
| **연방 기관** | 세관·항만청(원산·마산포 군항 직할)·연방 철도국 — 전속 사항 실무 기관 |
| **연방 대표** | 두마 42석 · 상원 8석(국회가 선출 — [[국가평의회]]) |
| **전왕 예우** | 덕수궁 거처와 세비. 세비는 한국 정부 예산에서 지출 |
| **군** | 평시 자체 부대 — 소총 편제의 치안·의장 병력, 야포·기관총 없음 |
| **재정** | 관세는 표준 규칙(연방 세관) — 세입은 직접세 중심으로 재편, 분담금은 인구 비례. **구 차관은 편입 시 연방이 인수·소각**(무부채 출발, [[한국_편입_경과_1918_1920]]) |
| **화폐** | 원(圓) 존속 — 1920~24 연방 국립은행 한성 지부의 위탁 발행을 거쳐 **1924년부터 한국은행**(1923 「한국은행법」, 탁지부 감독)이 발행. 루블 준비금 담보·고정 환율([[연방_재정과_화폐]]) |
| **연방 투자** | [[동방_개발_계획]]의 **교두보** — 개발비 최대 배정지. 극동~한반도 철도 연결·원산 상항 확장 |

## 3. 구성·조직

| 기관 | 내용 |
|---|---|
| 국회 | 단원제 150석, 한성 |
| 내각 | 총리대신 + 각부 — 의정부 계보 행정부의 개편 |
| 지방 | 13도 체계 유지 (관찰사–군수) |
| 전왕 예우 사무소 | 궁내부 잔무 승계 — 세비·능원 관리 |
| 두마 의원단 | 42석 — 협력계(연방 여당과 제휴)와 민족계(독자 회파)로 양분 |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1919.10.21 | 제8호 의정서 타결 — 국호에서 '제국' 제외, 유보 5종 + **청산·개발 3조**(구 조약·이권 실효 / 차관 소각 / 연방 투자). 급진파 조인 거부 선언 후 국경 밖 이산 |
| 1919.11 말 | **고종의 재가 — 마지막 국사 행위**([[한국_편입_경과_1918_1920]]) |
| 1919.12.6 | 헌장 공포 — 황실 폐지·차르 겸위. 반대는 상소·지면·철시로 표출 후 잦아듦 |
| 1920 | 첫 국회 선거 — 협력계 다수(명망가·관료·상공 기반), 온건 자주 계열 다수 참여로 민족계 원내 진입. 첫 의결 = 의정서 추인(가결 — 만장일치 아님, 민족계 일부 반대·기권). 궁내부 해체 · **연말, 추인·전환 이행 확인 후 구 차관 증서 소각식**([[한국_편입_경과_1918_1920]]) |
| 1921 | 동방 개발 계획 발족 — 개발비 최대 배정지 |
| 1923 | **「한국은행법」 제정** — 협력계·민족계가 함께 찬성한 드문 합의 법안 |
| 1924 | 제2차 국회 선거 — 협력계 다수 유지, **민족계 약진(약 3분의 1선)** · 태평양 정기 항로 개설(원산 기점) · **한국은행 발권 인수**(한국은행권 유통 개시) |
| 1925 | 국회 최대 쟁점 = 1929 유보권 갱신 협상 방침 |

〔편집 메타 OOC〕 왕관-현지 손 구조의 준거 = 독일 제국(카이저는 바이에른에 대리인 없음)·오헝의 헝가리(왕은 빈에, 부다페스트엔 책임 내각). 원역사 핀란드 총독은 전제 군주의 집행 대리인이라 이 체제에선 존재 근거가 소멸 — 여기에 협상장에서 한국 측이 공사관 정치의 기억으로 "사람"을 거절한 사정이 겹침. 민심 설계 = 표면은 실리(세금·학교·철도), 저류는 임금 잃은 충성심이 흘러 모이는 "임금 없는 민족" 정서(1기 인구 삼분 15/20/65의 1925년판) — 민족계 참여의 논리는 "임금은 이미 없다, 남은 자주는 조문과 예산으로 다툰다". 전왕 = 생존·침묵·이중 회색(참배 대상이되 부인 조서의 값으로 구심은 못 됨). 러시아 통제 장치는 제도가 아니라 정치(협력계 정렬·연방 전속 기관·차관)라는 구조 — 민족계가 다수가 되어도 왕관에게 한국 정부를 치울 법적 도구가 없다. 가드레일: 3.1·문화통치·왕공족 편입 등 원역사 복제 금지([[_고증_바이블]] §ⓕ·ⓛ), 일본식과의 차별선 = "왕관을 없애고 의석을 줬다". 국회 150석·1924 비율은 기준계.
