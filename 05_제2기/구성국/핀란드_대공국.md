# 핀란드 (대공국)

## 1. 개요

핀란드는 열세 구성국 가운데 **연방이 가장 얇게 닿는 곳**이다. 화폐·관세·우편·사법·시민권 명부 — 연방 전속을 가장 많이 뚫은 유보 목록을 가졌고, 병역 대신 세금을 낸다. 헬싱포르스 시민이 일상에서 연방을 만나는 곳은 국경 역뿐이다.

가입 문서의 문안은 **"대공국 기본법 질서의 확인"** — 핀란드에게 헌장은 새 질서가 아니라 옛 권리의 회복으로 적혔다.

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **지위** | 대공국. 차르가 "핀란드의 대공" 칭호로 겸위. 가입·유보는 제9호 의정서([[연방_가입_의정서_일람]]) |
| **유보권** | 자체 화폐(마르카 — 핀란드 은행)·관세·우편 / 평시 자체 부대 / 교육·종교 / **자체 시민권 명부** / 자체 사법(자국 종심) — 열세 구성국 중 최다 |
| **병역** | 징병·지원 모두 없음 — **병역세** 납부([[연방군]]) |
| **선거** | 두마 선거인 자격을 시민권 명부 유보가 정한다 — **남녀 보통선거**(성년 전원). 같은 두마에 구성국마다 다른 자격으로 선출된 의원이 앉는 대표 사례([[두마_선거법_1919]]) |
| **재가** | 구성국 법률의 기일부 재가 미러([[구성국_정부_구성]]) |
| **연방 기관** | 국경 세관뿐 — 관세·우편 유보로 그 밖의 연방 창구가 없다 |

## 3. 구성·조직

| 기관 | 내용 |
|---|---|
| 의회 | 단원제(에두스쿤타) — 남녀 보통선거. 1906년 이래의 제도가 그대로 |
| 원로원 | 합의제 정부 — **원로원 의장이 수반**(의회 신임) |
| 핀란드 은행 | 마르카 발행 — 루블 준비·고정 환율([[연방_재정과_화폐]]) |
| 두마 의원단 | ~11석 — 단일 회파, 사안별 거래([[정당_체계]]) |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1919.11.13 | 제9호 의정서 — 아홉 통 중 마지막 타결. 자체 시민권 명부가 조인식 전주에야 문안에 들어감 |
| 1920.1.1 | 시행 — **달라진 것이 가장 적은 구성국.** 우표도 화폐도 법원도 그대로, 바뀐 것은 문서의 근거 조항 |
| 1921 | 상원 6석 첫 선출 |
| 1923 | 분담금 사정 파동 — 인구 비례 산식 유지 측에 섬([[연방_권한_분장]]) |
| 1925 | 수반 회의 "동등 지위 선언" 채택안 — **핀란드가 앞장서 미는 쪽** |

〔편집 메타 OOC〕 준거 = 실제사 핀란드 대공국: 자체 화폐(마르카 1860)·독자 법제·단원제 의회와 남녀 보통선거(1906)·징병법 분쟁(1901 — 병역세 타결의 원형)이 전부 역사적 사실이고, 본작은 그 위에 러시아화(1899~) 상처의 공식 청산이라는 프레임을 얹었다. 무마 설계상 핀란드는 외부 공포가 없는 유일한 고위험 구성국 — 잡아두는 것은 유보의 실적과 간섭 제로의 기록뿐이라, 충성이 아니라 계산으로 남아 있는 구성국이며 이 불안정성은 의도적으로 보존한다(연방이 약속을 어기는 순간 첫 번째로 문을 보는 곳). 사법 유보는 2026-08-06 정합 보정으로 명시(최상 유보국이 자국 종심을 안 가진 것이 실제사·침투 실측과 모순이었음).
