# 러시아 (제국 본체)

## 1. 개요

러시아는 열세 구성국 가운데 가장 크며, 다른 열둘과 마찬가지로 **자체 의회와 정부**를 가진다. 수도는 **페테르부르크** — 왕관과 궁정이 있는 도시다. 연방 수도는 **모스크바**다.

1925년 현재 러시아 정부는 **농민동맹·국민동맹 연합**이다. 연방 여당인 진보당은 러시아 의회에서 야당이다.

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **지위** | 제국 본체. 차르의 칭호 "전러시아의 황제"([[국가헌장_조문]] 제3조 一) |
| **수도** | 페테르부르크 — 궁정(겨울궁전)도 이곳 |
| **의회** | 러시아 의회, 단원제 ~250석. 선거 자격은 연방 선거법과 동일 |
| **정부** | 수상은 러시아 의회의 신임으로 정한다 |
| **상원 몫** | **36석** — 러시아 의회가 선출([[국가평의회]]) |
| **유보권** | 없음 — 잔여권(헌장 제2조)만으로 운영되는 유일한 구성국 |
| **겸직 금지** | 연방 각료와 러시아 각료는 겸할 수 없다(조직법) |
| **가입 문서** | 의정서 없음 — 두마의 헌장 채택이 동의를 갈음([[연방_가입_의정서_일람]]) |

## 3. 구성·조직

| 기관 | 소재 |
|---|---|
| 러시아 의회·정부 | 페테르부르크 |
| 궁정 | 페테르부르크 (겨울궁전) — 차르는 두마 개회(헌장 제21조) 때 모스크바로 이동 |
| 연방 정부·두마·상원·대심원 | 모스크바 |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1919.12.6 | 「러시아에 관한 조직법」 공포 — 헌장과 동시. 러시아 의회·정부 설치, 연방-러시아 각료 겸직 금지 |
| 1920 | 첫 러시아 의회 개원(페테르부르크) — 명망가 다수 · 연방 기관 모스크바 이전 |
| 1923 | 분담금 납부 유예 (사정 파동 3국 중 하나 — [[연방_권한_분장]]) |
| 1924 | 제2차 의회 선거 — **농민동맹 대약진, 국민동맹과 연합 정부 성립** |
| 1925 | 상원 정기 개선 — 새 의회가 러시아 몫 개선분 18석을 선출([[국가평의회]]) |
| 1925 | 토지 법안 의회 상정 |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| **토지 법안** — 토지 제도는 구성국 잔여 사항이라 러시아 의회 관할 | 러시아 의회(농민동맹) ↔ 연방 정부 | 계류. 통과 시 연방의 토지개혁 유예 노선이 러시아 영역에서 무효 |
| 분담금 산식 개정 (인구→소득 비례) | 러시아 ↔ 발트·핀란드 | **1929 사정** |
| 페테르부르크 상공계의 이전 보상 요구 | 페테르부르크 시 ↔ 연방 | 청원 계속 |
