# 폴란드 (차르국)

## 1. 개요

폴란드는 **분할로 세 조각 났던 나라가 연방 안에서 다시 하나가 된 구성국**이다. 비스와 유역의 본체에 포즌이 강화에서, 갈리치아가 해체된 이중 제국에서 돌아왔다([[전후_국제_질서]]). 재통일은 연방 바깥 어디에도 없던 경로였고 — 그것이 이 구성국이 연방 안에 있는 이유의 절반이다. 나머지 절반은 국경 서쪽의 공기다.

## 2. 조문·규정 (골자)

| 항목 | 내용 |
|---|---|
| **지위** | 차르국. 차르가 "폴란드의 차르" 칭호로 겸위. 가입·유보는 제7호 의정서 — 최장 협상([[연방_가입_의정서_일람]]) |
| **영역** | 비스와 유역 본체 + **포즌**(1920, 강화 처리) + **갈리치아**(1920, 이중 제국 해체) + 리투아니아(1920, 발트와의 경계 타결 — [[연방_구성국_일람]]) |
| **유보권** | 교육·종교(가톨릭 완전 자치) / 자체 사법(자국 종심) / **평시 자체 부대 — "평시 편제" 문안**(규모 상한을 숫자가 아니라 말로 적음, 해석 미정) / 산업 규제 |
| **신영토 의석** | 포즌·갈리치아는 1924년 총선부터 **잠정 선거구**로 참여 — 인구 대비 과소 배정. 본획정은 1929년 재획정 시한([[두마_선거법_1919]] 부칙) |
| **연방 기관** | 세관·철도·우체국 — 침투 중간([[연방_권한_분장]] §침투 실측) |

## 3. 구성·조직

| 기관 | 내용 |
|---|---|
| 의회(세임) | 자국 의회 — 수상은 의회 신임([[구성국_정부_구성]]) |
| 두마 의원단 | 폴란드 콜로 ~30석 — 최대 구성국 회파. 신영토 본배정 전이라 인구 대비 적다([[정당_체계]]) |
| 평시 부대 | "평시 편제" 문안의 실행체 — 향토 편성. 규모·장비의 해석을 양측 모두 아껴둠([[연방군]]) |

## 4. 연혁

| 연도 | 사실 |
|---|---|
| 1919.9.30 | 제7호 의정서 타결 — 아홉 협상 중 최장. "평시 편제" 문안 성립 |
| 1920 | **포즌·갈리치아 귀속** — 재통일. 리투아니아 경계 타결(폴란드 귀속) |
| 1924 | 신영토 잠정 선거구로 첫 총선 참여 |
| 1925 | 국회·콜로의 공통 의제 = 1929 재획정에서의 의석 본배정 |

## 5. 계류 현안

| 건 | 당사자 | 상태 |
|---|---|---|
| **신영토 의석 본배정** — 두마 재획정·상원 배정(10석은 1919년, 재통일 전 기준) | 폴란드 ↔ 연방 | **1929** |
| "평시 편제" 문안의 해석 | 폴란드 ↔ 군무부 | 양측 모두 해석을 아껴둠([[연방군]]) |
| 서부 국경 — 수정주의 독일과의 접경 관리 | 폴란드 ↔ 연방 외무부 | 상시 |

〔편집 메타 OOC〕 무마 설계의 핵심 = "독립보다 먼저 통일을 준다": 분할 이전 영토의 재결합은 연방 안에서만 가능한 경로였고(포즌·갈리치아는 강화 테이블의 전리품), 봉기 대신 흥정을 택할 물질적 이유가 됐다. 보조 접착제 = 독일 수정주의의 방패(외부 공포 ⑤). 재통일의 값이 대표성의 시차로 남은 것이 이 프로필의 축 — 1919년 배정(인구 1,400만 기준)이 1920년 재통일로 낡아버려, 폴란드는 제 몫보다 적은 의석으로 1929년을 기다린다(기존 canon의 선거구 재획정·유보 갱신 시한과 자동 합류). 갈리치아·포즌 인구 편입은 원역사 준용(갈리치아 ~800만·포즌 ~200만 규모의 기준계). 리투아니아의 폴란드 귀속은 08-03 canon(경계 분쟁 표) 그대로.
