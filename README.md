# ⭐ 「북극성 아래」 — 대체역사 소설 집필 Vault

1915년, 러일전쟁에서 이긴 러시아 제국. **전제군주정이 무너지지 않고 비워지는 이야기**를 쓰는 Obsidian Vault.

> 왕관은 그대로 있고 실권만 옮겨 간다 — 쿠데타가 아니라 청구서로.

**너가 방향을 정하면 → 네모(AI)가 초안을 쓰고 → 너가 확정한다.** 배경 설정은 동결돼 있고, 소설만 앞으로 나간다.

## 시작하기 (Obsidian 연결)
1. Obsidian 앱 실행 → **"Open folder as vault"** → 이 폴더 선택.
2. 끝. 그래프 뷰 / 위키링크 / 템플릿이 이미 켜져 있다 (`.obsidian/` 동봉).
3. 첫 화면: 소설은 [[_집필_MOC]], 세계 설정은 [[세계관_허브]].

> 참고: 네모(Claude Code)와 Obsidian은 **같은 폴더를 공유**할 뿐 실시간 연결은 아니다.
> 네모가 md를 고치면 Obsidian에 즉시 반영되고, 반대도 마찬가지.

## 두 개의 층

이 Vault는 **동결된 배경**과 **앞으로 나가는 소설**로 나뉜다. 섞지 않는 것이 운영의 대원칙이다.

### 🔒 배경 (canon) — 동결
| 폴더 | 내용 |
|---|---|
| `00_세계관개요` | 전제·테마·[[톤_바이블]]·수치 모델 |
| `10_인물` | 인물 설계도 |
| `20_지역` | 장소·지리 |
| `30_세력` | 조직·집단 |
| `40_체계` | 제도·구조 — 일관성의 핵심 |
| `50_연표사건` | 역사·사건 |
| `60_용어개념` | 용어집 |
| `_MOC` | 색인([[세계관_허브]] + 카테고리별 7종) |
| `_템플릿` | 노트 양식 · frontmatter 표준 |

집필 중 **건드리지 않는다.** 예외는 명백한 모순 수정, 또는 이야기가 새 설정을 실제로 요구할 때뿐이고, 그때도 [[세계관_범위와_경계]]의 canon 해동 절차를 탄다.

### ✒️ 소설 — 살아 움직이는 층
| 폴더 | 내용 |
|---|---|
| `80_집필` | 헌법([[_집필_규칙]]) · 문체([[_문체_바이블]]) · 질감([[_고증_바이블]]) · 플롯 · 스레드 |
| `90_원고` | 회차 본문 `NNN화_제목.md` |

- 구조: **전 43화 3부** — 1부 「압력솥」(001~013) · 2부 「청구서」(014~028) · 3부 「환수」(029~043)
- 설계 3층: [[플롯_아웃라인]](큰그림) → 부 플롯(블록) → 회차. 전체 조망은 [[_전체_구조_설계]]
- 톤 계약과 권력 이양 사다리: [[_v3_설계서]]

## status — 두 트랙
- **설정 노트**: `씨앗 → 초안 → 구체화 → 완성`
- **원고**: `구상 → 초고 → 퇴고 → 탈고`

## 회차 사이클
초안 → 피드백·퇴고 → **너의 "확정" 한마디** → 검수 1패스(★작성자 ≠ 검수자) → [[작중_타임라인]]·스레드·[[집필_확정_사실]] 갱신 → 커밋·푸시.
절차 전문은 [[_집필_규칙]] §7.

## 무결성 검사
```
python _scripts/frontmatter_lint.py
```
frontmatter 필수 8필드·enum·moc 해결을 전수 검사한다. **위반 0**이 정상.

## 권장 플러그인 (선택)

- **Templater** — 템플릿 자동 삽입 강화 (코어 Templates로도 충분)
