# 「원과 루블」 플롯 아웃라인

> **대아크**: 1925(17세, 원산 여학교 졸업반) → 모스크바 유학 → 1929(21세, 판이 다시 짜이는 해). 성장의 시계와 세계의 시계가 같은 해에 울린다.
> 1부 = 사용자와 공동 설계 확정(2026-08-10). 2부 이후 = 골격만 — **착수 전 공동 설계.**

## 1부 「원산의 신문」(가제) — 1925~1926 이른 봄 ★완결(2026-08-11, 전 16화 확정)

> **1부 전체 점검 결과(확정 시)**: 셋업/페이오프 대차 무결 — 화요일 리듬·환전 창구·"저 기차는 열이틀"(001→016), 읽어 주는 값(001→013 역전→016 선물), 신문 못(003→009→016 인수), 셈 종이·유보 조항(009→014), 정초석(002→015), 잡지 열두 권(002→012, 첫 권 바이칼은 2부 회수), 부적(010→012→016 재장전), 교본·사진사·빵집(004→015·016), 명단의 시대(007→015 "예과" 어긋남). **2부로 열린 화약 8**: 부적 전신 / "모스크바 서점에서" / 민영신 재회 / 어머니 주소 쪽지 / 채 노인 "종이 파는 데" / 바이칼=첫 권 / 윤복 러시아 글자 편지 / 김표도르 "가서 보거라"(이름의 속). 의도적 장기 씨앗: 둘째 권 백야(페테르부르크)·금란 혼사(봄, 편지 소식).

**뼈대 = 관심 → 기회 → 유학.** 거래도 쟁취도 아닌 자연스러운 이끌림의 세 박자.

**1부의 진짜 주인공 = 분위기** — 1920년대 연방 시대 조선, 변화된 것과 이국적인 것이 섞인 항구도시 원산([[한국의_연방_풍경_1925]]가 팔레트). 이화의 일상 동선이 곧 세계 관광이 되도록: 부두 게시판의 전문(電文) 시세 — 조선어·러시아어 병기 간판 거리 — 며칠 늦는 모스크바 신문 — 정교회 종소리 — 원과 루블이 섞이는 거스름돈 — 원산역을 지나는 **모스크바행 직통(편도 12일)**.

| 박자               | 내용                                                                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **관심** (봄~여름)    | 활자로 세상을 읽는 이화의 일상 — 학교(노어 수업·급우들의 진로 이야기), 상회(강 서방에게 옮겨 주는 시세), 신시가 판매소(채 노인, 늦게 닿는 모스크바 신문). 세계 브리핑은 전부 그녀가 읽는 지면과 걷는 거리로             |
| **기회** (여름~가을)   | **연방 유학생 선발**([[한국_학제_1925]]) — 제도가 원래 깔려 있고, 노어 교육 있는 해성여학교가 추천권을 가진 학교. 김표도르의 추천 → 교장의 승인 → **한성 본시험**(러시아어·산술·작문 — 이화의 첫 한성행, 첫 기차) |
| **유학** (겨울~늦겨울) | 합격 통지 → 집안의 승낙(관비여도 생활비는 자담 — 아버지의 주판, 어머니의 흔들림, 조부의 뜻밖의 한마디) → **1926년 2월 중순, 당겨진 졸업식 다음 날 원산역에서 모스크바행 직통에 오르며 1부 닫음**                               |

### 회차 지도

**★블록 1 「관심」 001~006 — 확정(2026-08-10).** 화마다 도시의 얼굴 하나 + 그날의 작은 일 하나:

| 화 | 내용 |
|---|---|
| 001 | **신문 아침** — 신문 뭉치가 닿는 아침, 판매소 가는 길의 원산(병기 간판·부두), 채 노인. 닫기 = 원산역, 떠나는 모스크바행 직통("저 기차는 열이틀을 달린다지") — 1부 마지막 화와 수미상관 |
| 002 | **학교** — 노어 수업·김표도르, 정임·금란, 졸업반의 진로 공기 |
| 003 | **상회** — 가족 소개, 부두와 강 서방. 이화가 옮긴 신문 시세가 처음 "쓸모"가 되는 날 |
| 004 | **신시가** — 러시아인 거리·정교회 종·상점. 이국 관광의 절정 화 |
| 005 | **별** — 마리아 기사를 읽는 화("페테르부르크에는 여자 재상이 있다더라") |
| 006 | **여름의 물음** — 급우들의 진로가 정해져 가고, 이화에게는 물음표만. "너는?"으로 블록 닫기 |

**★블록 2 「기회」 007~012 — 확정(2026-08-10 개정).** 계기 = **모스크바 연방 대학 구성국 학생 모집 공고**: 공고 자체는 전부터 있었으나 선발이 한성 학교 추천 명단 위주 → **1925년 공개 경쟁 시험으로 전환, 지방 인가 학교·여학생에게 응시 길 확대**([[한국_학제_1925]]) — 005화 "조선 여자는 언제 되나"의 답이 지면으로 도착하는 구조.

| 화 | 내용 |
|---|---|
| 007 | **공고**(7월 말, 방학 중) — 판매소에서 제 것인 줄 모르고 소리 내어 읽다가 한 줄에서 멈춤. 처음으로 신문을 제 돈으로 사는 날 |
| 008 | **그때 가서 할 얘기** — 김표도르의 서랍에도 같은 공고(열두 권 시계 회수·추천), 교장 한봉례의 추천서. "어디까지 가 보나"가 모스크바라는 이름을 얻음 |
| 009 | **집안의 셈** — 아버지 주판·어머니 흔들림·혼담 방패 콜백, "시험이나 보게 해 달라"까지 |
| 010 | **가을 공부**(8~9월) — 김표도르 특훈 = 문어·격식체(그녀의 오르막이 곧 시험 과목), 정임의 가을 시험과 나란한 두 공부 |
| 011 | **첫 기차**(10월) — 한성행 + 본시험 |
| 012 | **기다림**(11~12월) — 정임 합격(문이 열린다는 증거가 먼저 옴) → 블록 닫기 |

시간 검산: 블록 1(~7월) 무수정 → 공고 7월 말 → 특훈 두 달 → 시험 10월 → 결과 12월 → 당겨진 졸업식 1926년 2월 중순 → 다음 날(화요일) 출발. **합격 = 본과 입학 확정** — 구성국 신입 준비 학기 3월 1일 개강·2월 말까지 도착이 출발 시계의 근거(통지서 문면). 준비 학기(3~8월, 어학·강독) → 9월 정규 학년 진입(러시아권 1921 학년도 통일령). "예과"는 김표도르 세대의 옛 명칭(008 대사에만 존재).

**★블록 3 「유학」 013~016 — 확정(2026-08-10).**

| 화 | 내용 |
|---|---|
| 013 | **통지**(12월) — **세 종이의 경주**: 전신 탄 한성 조간(판매소에서 남의 소식처럼 읽다 제 이름 발견) → 개별 통지서(본과 입학 허가·준비 학기 3월 개강·2월 말까지 도착 문면 = 2월 중순 출발의 시계) → 열이틀 뒤 모스크바 신문 관보란에서 러시아어로 제 이름 재독. 012 예약(채 노인 "여기 와서 제일 먼저 읽어라")·금란 "신문에 나는 쪽이 돼" 회수 |
| 014 | **결정**(12월~1월) — 009 유보 조항("붙고 나서 보낼지는 그때 또 셈한다") 해소, 셈 종이의 "붙는 칸"이 현실이 되는 저녁상. **조부 카드 개봉**(사랑방 열린 문 → 뜻밖의 한마디). 어머니의 채비("반대와 채비는 같은 마음의 두 손" 완결) |
| 015 | **작별 = 당겨진 졸업식**(2월 중순, 월요일) — 개교 16년 첫 대학행의 기차 시간에 학교가 달력을 맞춤. 작별이 나열 아닌 하나의 사건. 한봉례·김표도르(노어 교본 회수)·정임·금란 |
| 016 | **원산역**(다음 날 화요일) — 001 수미상관: 승강장 안쪽, 루블 환전 첫 실행("먼 길은 루블로"), 화요일 저녁 직통 승차, 가족·채 노인 배웅, 기차 안에서 신문 펴기. 닫기 = "이제 그녀도 열이틀을 간다"(종이의 속도) — 1부 끝 |

2부 씨앗은 회수하지 않고 보존: 부적 전신(정임)·"다음 책은 네가 사거라, 모스크바 서점에서"·담 밑 여학생.

전체 15~18화 밴드 내 ±2화 유연(한성 2화 분할 등).

- 갈등의 온도: 낮게 — 반대는 벽이 아니라 문턱(넘어가는 데 마음의 값이 드는 정도). 이 부의 긴장은 "될까"보다 "떠나는 무게".
- 분량: 유연(사건보다 분위기 중심이라 짧아도 됨) — 집필 착수 시 블록 단위로 결정.

## 2부 「모스크바」(가제) — 1926 한 해 ★완결(2026-08-11, 017~030 전 14화 확정)

> **2부 전체 점검 결과(확정 시)**: 셋업/페이오프 대차 무결 — 바이칼 첫 권(002→018), 주소 쪽지(016→019), 부적 전신(012→019 가동), 담 밑 여학생(011→020 "바꾸자"), 채 노인 단골 예약(016→021), 읽어 주는 값 재연(001→021), "표를 파는 사람"(021→024→027 확산), 연필→잉크(025→029), 저울추(014→018→029 "말함"), 서점 첫 책(012→030 헌사). **3부로 열린 화약**: 갱신 단신(030, 1929 시계) / 소피야 "이 년 뒤 큰 조사, 손이 모자랄 거예요"(029) / 영신 부 "숫자만 보내지 말고 사람도"(027) / 찻집 벽 "내년에 또"(030) / 베라 인쇄소 초대(028) / 김표도르 "그때 가서 말씀드리겠습니다" 후속(029→030 소포 도착 반응) / 둘째 권 백야(페테르부르크, 장기) / 금란 함흥 살림·윤복 러시아 글자 편지.

1부와 대칭: 한 도시, 한 해, 계절 순환. **부 사이다 = 전공 확정 + 모스크바 서점에서 첫 책을 사는 장면**(012 "다음 책은 네가 사거라" payoff). **정서 축 = 거리 모티프의 역전** — 이제 원산이 열이틀 하류(정임 전보·윤복 편지·금란 혼사가 늦게 닿는 쪽).

| 026 「나라를 세는 방」(10월) | 전공의 물음 본격 — 공통 학기의 두 강의실(경제 vs 문헌)을 오가는 이화 / ★**통계국 열람실 방문**(과제 자료 열람, 소피야 안내) — **극동 인구 대장 속 조선 이름들**(원호인 마을들이 숫자로 — 숫자 속에 사람이 있다는 발견 = 전공 결정의 씨앗, 변화하는 조선 축과 교차) / 명태 상인 계약서 후속(영신과 합작 = 법과 경제) |
| 027 「밀물」(10~11월) | 10월 개회 — 도시의 밀물(아홉 역·열세 나라 의원, 한국 의원단 원경 — 신문 정치면이 거리 실물로) / **정임 제복 사진 도착**(견습 만기·정식 임용 = 유리벽 payoff) / **모스크바 첫눈** — "이 눈은 한 달 뒤에 원산에 간다"(012 거리 모티프의 완전 역전) |
| 028 「교수 앞의 열 걸음」(12월) | 첫 **구술시험**(가을 학기말 — 러시아 대학 전통, 교수 앞 문답) / 이화의 차례: "빵값은 누가 정하는가"에 원산 부두로 답함(제 세계로 학문을 받는 순간) / 학부 확정 마감 임박 |
| 029 「잉크」(12월 말) | ★**전공 확정 = 경제학부** — 성탄 방학의 결정: 얼굴들의 통합(통계국의 조선 이름들+아버지의 물가란+민타이 — 숫자가 사람을 지키는 도구일 수 있다는 답), 저울추가 마침내 말함 / **연필 글자 위에 잉크로 같은 글자를 눌러 적음**(025 복선 회수) / 편지로 알림(집·김표도르) |
| 030 「타티야나의 날」(1927.1) | 대학 축일 — 제복 학생들의 축제 / ★**부 사이다 = 모스크바 서점에서 첫 책**: 열두 권 잡지의 **최신 호**를 사서 김표도르에게 부침("다음 호는 없다"던 12권 뒤의 다음 호를 제자가 보냄 = 012 payoff 완성) / 1년 회고(원산의 신문→모스크바의 학생) / 3부 훅: 신문 정치면의 갱신 준비 단신을 처음으로 유심히 읽음(1929 원경) — **2부 끝** |

**전공 = 경제·통계(확정 2026-08-10)** — 작중에서는 준비 학기~첫 학기에 걸쳐 선택 과정으로 극화. 활자는 부업·기질로 유지(유학생 회보·통신 곁가지). 1929 통로 = 통계국([[연방_행정과_문관제]] "분모 제조처")·재무부 조사 라인. 김표도르의 낡은 어휘("예과") 발견 장면 = 블록② 재료.

## 3부 「세는 사람」(가제) — 1927~1929 (구조 확정 2026-08-11, 사용자 방향 위임)

> **사용자 방향(2026-08-11)**: ①속도 상향 — 졸업까지 + 졸업 후 어디로 향하는지 ②**1년에 한 번 조선 귀향**(1927·1928·1929 각 1회) ③종착 = **대학 졸업 후 연방 관청 지원**(= 통계국, 026·029 씨앗의 직선) ④그 사이에 기획분(1929 유보 갱신·1928 인구 조사·극동 학교 쟁점) 배치.
> **페이스**: 2부 = 1년 14화 → 3부 = **3년 12화**(연 4화). 계절 도약 크게, 블록 사이 시간 건너뜀은 브리핑 한 문단.
> **학사 시계**: 본과 3년제(025~030 확정) — Y1 1926/27 → Y2 1927/28 → Y3 1928/29 → **졸업 1929년 5월**(국가시험 = 구술). 갱신 만료 = 1930년 초 → **협상의 해 = 1929**(030 단신과 정합).
> **부 사이다**: ①조사원의 여름 — 종이로만 알던 마을을 제 발로 걷고 제 손으로 셈(026 payoff) ②문관시험 합격·통계국 임용 — 반년짜리 열람증의 방에 제 책상이 생김 ③1929 갱신 테이블로 올라가는 표 하나가 그녀 손을 거침(결말 = 테이블 끝자리 도달, 갱신 자체의 결말은 안 그림 — 위키 영역).
