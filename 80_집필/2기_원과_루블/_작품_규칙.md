# 「원과 루블」 (가제) — 작품 규칙

> **로그라인**: 1925년 원산. 활자로 세상을 읽던 객주의 딸 최이화가 신문 너머의 세계 — 연방의 수도 — 로 가는 문을 지나, 판이 다시 짜이는 해 1929년에 닿기까지.

「북극성 아래」와 **같은 세계, 다른 계약**이다. 무대는 제2기 위키(1925~)이고, 이 문서가 이 작품의 헌법이다. 「북극성 아래」의 규칙·문체 바이블은 그 작품 전용 — 여기 명시적으로 이식한 조항만 유효하다.

## §1 형식 계약

| 항목 | 규칙 |
|---|---|
| 형태 | 웹소설 연재형 — 단일 주인공(최이화) 밀착 서사 |
| 시점 | **3인칭 단일 밀착** — 초점은 주인공 고정. 예외 = 인터루드(막간) 회차만 타 시점 허용, 부당 0~2회 |
| 회차 분량 | **5천자대(4,500~6,000, 공백 포함·줄바꿈 제외)** — 한 회차 = 한 호흡 |
| 연재 리듬 | **훅·절단·회차별 사이다 의무 없음.** 회차는 호흡 단위일 뿐, 이야기는 연속체 — 이어지는 느낌 그대로 가도 된다 |
| 보상 설계 | 사이다는 **부(部) 단위**로 확실히 — 부가 닫힐 때 성취가 눈에 보여야 한다. 회차 단위는 자유 |
| 집필 단위 | 블록(3~5화)을 한 컨텍스트로 이어 쓰고, 확정 게이트에서 블록 통째 검수 |
| 회차 파일 | `90_원고/2기_원과_루블/NNN화_제목.md` — 번호는 이 작품 독립 채번(001화~) |

## §2 톤 계약

- **네이티브 전문가물.** 치트 없음 — 주인공의 무기는 셈·말·눈뿐이고, 오르는 길은 세계가 이미 깔아 둔 사다리(학교·시험·신용)다.
- **성장의 온도는 밝게, 세계의 회색은 정직하게.** 소년이 크는 이야기의 활기를 유지하되, 힘 관계의 리얼리즘은 「북극성 아래」와 공유 — 러시아 우위는 정직하게, 한국의 몫은 조문과 실력으로 넓어진다. **주인공은 세계를 이기는 게 아니라 세계의 문법을 익혀 오른다.**
- 민족 감정은 저류로 존재(2기 canon: 표면 실리·저류 민족) — 설교도 냉소도 아닌, 소년의 눈에 걸리는 장면으로.
- 웹소설 문법은 **도구로 차용하되 목표로 삼지 않는다**(1기 교훈 승계) — 형식은 그릇, 이야기가 주인.

## §3 canon 관계

- **1기 canon(00~60, 1915 동결) + 2기 위키(2기_1925/)** = 무대 설계도. 소설은 그 **결과 세계를 산다** — 2기 서술 원칙과 같이, 본문에서 "무엇이 바뀌었는지"를 해설하지 않고 1925년의 현재를 살아 있는 것으로 그린다.
- 원고가 창조하는 사실(인명·상호·수치·소품)은 이 작품의 **확정 사실 원장**(첫 확정 시 `집필_확정_사실_원과루블.md` 신설)에 등재. 「북극성 아래」 원장과 별도.
- **1기 인물 카메오 = 최소·먼 배경** — 신문 속 이름, 소문 속 직함. 정면 등장은 사용자 승인.
- 위키에 없는 배경이 필요해지면: 사소한 빈칸 = 집필 중 창작 후 원장 등재 / 제도급 = 위키 노트 신설(2기 확장은 자유이므로 막히지 않는다).

## §4 문체 노트 (초기)

1. **독자 배려** (1기 v2의 유효 알맹이 이식): 독자는 설정집을 안 읽었다 — 인물 첫 등장에 "누구고 뭘 원하는지" 감 잡히게(효과만 요구, 방법 자유·서식 금지), 재등장 리마인드, 세계 브리핑 허용. **이 작품의 브리핑 장치 = 수업·장사 현장·부두** (교실과 장부가 세계를 설명한다).
2. **레지스터**: 중립 서술체 단일 — 학생·상인의 세계라 경어 서술체 구간 없음.
3. **반복 경계**: 「북극성 아래」 `_문체_바이블` §10(어휘·문단 복붙 금지)·§11(구조 반복 타파) 원칙을 포인터로 이식.
4. **메타누수 절대 금지**: 본문에 회차 번호·"앞 화에서" 금지 — OOC에만.
5. **숫자의 온도**: 장부·시세·환율은 이 작품의 무기지만, 회계가 기본값이 되지 않게(1기 §13 교훈) — 결정적인 순간은 숫자가 아니라 사람이 정한다.
6. **★원산의 밀도**(사용자 피드백, 001화): 원산은 한국 제일의 무역·왕래 도시 — **연방의 향기는 깃발(기관)이 아니라 사람으로 낸다.** 수병·선원·철도 제복·거류지 부인·러시아 단골이 거리의 기본 인구이고, 러시아 말은 파도 소리 같은 배경 소음. canon "행정 건물 없음"은 기관의 얘기지 사람의 얘기가 아니다 — 거리는 늘 붐비게.
7. **기준 문장 샘플(§9격)**: 1~2화 확정 후 이 문서에 채운다.

## §5 파이프라인

1. 블록 초안(네모) → 사용자 피드백 → **"확정" 한마디에만** 확정 처리.
2. 확정 시: 검수 5축(별도 컨텍스트 또는 main 직접 — 축① 대조 대상 = **1기 canon + 2기 위키**) → 작중 타임라인·확정 사실 원장 갱신 → **git 커밋 + push**.
3. 미확정 초고는 미커밋 유지.
