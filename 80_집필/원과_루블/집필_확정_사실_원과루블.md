# 「원과 루블」 확정 사실 원장

> 확정(퇴고↑) 회차가 창조한 사실만 등재. 원고와 어긋나면 원고가 이긴다. 갱신 = 확정 파이프라인 §5의 한 단계([[_작품_규칙]]).

## 회차 ↔ 작중 시간

| 화 | 제목 | 작중 시간 | 무대 |
|---|---|---|---|
| 001 | 열이틀 묵은 신문 | 1925년 4월, 화요일 | 원산 — 신시가·판매소·상회·원산역 |
| 002 | 가르치지 않은 말 | 1925년 4월, 평일 | 해성여학교 |
| 003 | 신문 두 부 | 1925년 4월, 토요일~닷새 뒤 | 원흥상회 안팎 |

## 확정 사실

| 분류 | 사실 | 출처 |
|---|---|---|
| 리듬 | **모스크바 신문은 화요일에 닿는다** — 부산발 직통 내려오는 편이 월요일 밤 원산에 신문을 부리고, 올라가는 편은 화요일 저녁 원산역을 떠난다 | 001 |
| 리듬 | 모스크바 지물 신문 = 열이틀 묵음 / 전신 소식 = 이튿날 한성 조간 | 001 |
| 장소 | **채 노인의 판매소** — 신시가 초입, 서점 겸 신문 판매소. 모스크바 신문의 첫 손님은 거류지 러시아인들 | 001 |
| 장소 | **원흥상회** — 부두로 내려가는 길목, 창고 두 채와 마당 | 001 |
| 장소 | 원산역 — 붉은 벽돌 낮은 지붕, 역명판 2행(조선어·러시아어). 매표 창구 옆 환전 창구(원→루블). 이화의 구경 자리 = 울타리 밖 화물 계단 | 001 |
| 관계 | **"읽어 주는 값"** — 채 노인(러시아 글자 못 읽음)에게 이화가 첫 장을 소리 내어 읽어 주는 것이 신문 값. 못 다 읽으면 외상 | 001 |
| 관계 | 아버지 최만석의 신문 = 물가란(4면)부터. 딸의 신문 심부름이 이 집의 화요일 | 001 |
| 소품 | 모스크바 신문 한 부 = 오 전 남짓(거류지 사람·해관 서기의 값) | 001 |
| 세계 | 모스크바 신문 셋째 장에 원산 축항 단신 — "종이는 한쪽으로만 달리지 않는다" | 001 |
| 세계 | 원산 = "이 나라에서 제일 빨리 크는 항구, 몇 해면 인천도 넘는다는 소리" — canon 보정(2026-08-10)과 정합 | 001 |
| 어구 | "생활은 원으로 하고 먼 길은 루블로 간다" — 강 서방의 말버릇(인용으로 첫 등장) | 001 |
| 어구 | "멀다는 것과 못 간다는 것은 다른 말이었다" — 이화의 발견(유학 씨앗) | 001 |
| 장소 | 해성여학교 — 신시가·구시가 사이 언덕, 운동장에서 항구가 내려다보임. **교문 정초석에 출자 객주들 이름(최만석 포함 — 창고 반 채 값)** | 002 |
| 사실 | 졸업반 = 입학 서른둘 → 열아홉. 노어 성적 = 이 학교의 자랑(어느 문의 열쇠인지 아버지들이 앎) | 002 |
| 관계 | **김표도르의 잡지 열두 권** — 페테르부르크 지리·기행 잡지, 겉장 안쪽에 그의 러시아 이름+옛 도시명+연도. 첫 권 = 바이칼 기행. "다 읽으면 다음 호" | 002 |
| 어구 | "그게 읽는 법이다" — 김표도르(아는 낱말로 사이를 메우는 것) | 002 |
| 사실 | 정임 전신 견습 시험 = 가을(국문·산술·수신 실기), 정식 월급 스무 원. 금란 집 = 한성 신문 원산 지국 | 002 |
| 사실 | 원흥상회 취급(정어리 철) = 어유(魚油)·마른 정어리 — 블라디보스토크行 통에는 조선어·러시아어 두 표 | 003 |
| 사건 | 어유 열흘 보류 — 이화의 조간 기억(북쪽 흉어)+강 서방의 뱃삯 셈 반반 → 시세 상승으로 이문. "다리란 건너 봐야 아는 물건"(이화의 자각) | 003 |
| 소품 | 조부 최덕구의 막대저울(갑오년 이전 물건) · 창업사 세 문장("남들이 무서워할 때 배에 먼저 올라갔다…") | 003 |
| 어구 | "읽는 눈이 하나씩 느는 게 이 집 내력이다" — 조부 / "신문에 나면 이미 늦은 소식" — 어머니(계 정보망) | 003 |
| 제도 | **"다음부터 두 부 사 오너라"** — 상회 구독 개시, 사무방 벽의 신문 못(윤재 비품 대장: "비품, 신문 걸이, 못 한 개") | 003 |
