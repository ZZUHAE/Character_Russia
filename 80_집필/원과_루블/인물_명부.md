# 「원과 루블」 인물 명부

> 전원 원고 창조 인물 — 1·2기 canon 인물과 무관(카메오 원칙은 [[_작품_규칙]] §3). 첫 등장 회차 확정 시 원장에 등재.

## 주인공 — 한도원(韓道源)

| 항목 | 내용 |
|---|---|
| 출생 | **1909년, 원산** — 1925년 현재 17세(세는나이). 1917년 총성을 여덟 살의 소문으로, 1919년 편입을 열한 살의 관보 낭독으로 기억하는 **연방 첫 세대** |
| 신분 | 객주 **원흥상회(元興商會)** 둘째 아들. 사립 **해성학교** 졸업반 |
| 무기 ① | **셈과 장부** — 집안 피. 러시아식 복식부기를 세관 서기의 헌 교본으로 독학, 아버지의 단식 장부를 몰래 복식으로 다시 적어 본다 |
| 무기 ② | **러시아어** — 학교 수업이 아니라 부두에서 익힌 실전어. 격은 틀려도 값은 안 틀린다 |
| 무기 ③ | **시세를 읽는 눈** — 화물·환율·소문 사이의 패턴이 남보다 먼저 보인다. 본인은 아직 이것이 재능인 줄 모른다 |
| 약점 | **열일곱의 신용 없음** — 장부는 읽는데 도장이 없다. 이 세계에서 거래는 실력이 아니라 신용이 하고, 신용은 나이와 이름이 한다. 이 간극이 성장 서사의 엔진 |
| 욕망 | 가업 승계는 형 몫 — 도원이 원하는 건 **원과 루블이 만나는 자리**, 즉 더 큰 판. 다만 1925년 시점엔 그것이 무역인지 은행인지 시험인지 본인도 모른다(1부가 이 질문) |
| 기질 | 숫자 앞에서 침착, 사람 앞에서 반 박자 늦음. 셈이 끝나기 전엔 말하지 않는 버릇 |

## 가족 — 원흥상회 (3대 = 변천 3시대)

| 인물 | 내용 |
|---|---|
| 조부 **한덕구**(1855년생, 생존) | 개항(1880) 무렵 덕원 장사꾼에서 객주로 — **구한말의 사람.** 은퇴 후 사랑방에서 옛 저울을 닦는다. 러시아 말을 끝내 안 배웠다 |
| 부 **한만중**(1878년생) | 2대 주인 — **보호국기의 사람.** 러 군납(건어물·잡화)으로 상회를 키웠고, 해관 담보의 시절을 어음으로 버텨 냈다. 신중이 병이 된 장사꾼 — "남는 장사보다 안 죽는 장사" |
| 형 **한도익**(1902년생) | 승계 수업 중 — 성실하고 셈은 평범. 동생의 눈을 시기하지 않고 **쓸 줄 아는 형** (가족 갈등 클리셰 배제 — 형제는 협력 관계, 긴장은 바깥에서 온다) |
| 모 김씨 | 안살림과 계(契) — 원산 상인 아낙들의 정보망 쪽 사람 |
| 누이 **한도희**(1912년생) | 여학교 재학 — 전신국을 꿈꾼다(2기 canon: 여학교 졸업생을 받아 주는 좁은 문) |

## 학교 — 해성학교(海星學校)

1909년 원산 객주 조합·교회 합작 설립 사립 중학교(5년제, [[한국_학제_1925]]). 노어 교사 초빙으로 이름났고, 졸업생 진로 = 가업·철도학당·상업전문·연방 유학의 네 갈래.

| 인물 | 내용 |
|---|---|
| 교장 **오병렬**(1868년생) | 설립 상인 조합 측 — 반은 교육자, 반은 회계. "학교도 장부가 맞아야 산다" |
| 노어 교사 **최표도르**(1885년생) | 연해주 원호인 2세 — 페테르부르크 유학 실패 후 교사로. 두 세계 어디에도 온전히 못 속하는 사람(1기 [[러시아_제국_내_조선인_사회]]의 인격화). 도원의 러시아어에서 부두 냄새를 맡고 눈여겨본다 |
| 한문 선생 **유 훈장**(1860년대생) | 구세대의 결 — 좁아지는 말의 마지막 교실. 도원의 조부와 바둑 친구 |
| 급우 **박기석**(1908년생) | 철도학당 지망 수재 — 집이 가난해 **가장 확실한 사다리**가 필요한 쪽. 도원과 셈으로 겨루고 노선으로 다투는 친구 |
| 급우 **임형규**(1909년생) | 민족계 신문 애독자 — 저류 민족 정서의 교실 내 목소리. 적이 아니라 질문을 던지는 자리 |

## 부두·거리 (1부 등장분)

| 인물 | 내용 |
|---|---|
| 지배인 **강 서방**(1880년대생) | 원흥상회 실무 총괄 — 도원에게 부두의 문법(하역·창고·구전)을 가르친 실질적 스승 |
| 세관 서기 **곽인호**(1890년대생) | 한국인 고원(雇員) — 도원에게 복식부기 교본을 판 사람. 문관시험을 몇 해째 벼르는 중(사다리의 중간에 낀 세대) |

## ❓ 미해결
- 러시아 측 인물(한국은행 원산지점·세관의 러시아인)은 2부 진입 시 조형 — 1부는 조선인 세계 중심으로 간다.
- 원흥상회의 주력 취급품(명태·대두·우피 중) = 1부 개시 사건과 묶어 집필 시 확정([[플롯_아웃라인_원과루블]]).
